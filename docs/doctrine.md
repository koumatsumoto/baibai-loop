# Doctrine

健全な企業の割安な機会を探し、日本個別株の現物で資本を運用する。根拠付きの将来価値・支払価格・成立条件・確からしさ・実現時間を比べる。株価下落だけを割安とせず、上昇中の割安も対象にする。

<a id="investment-strategy"></a>
## 投資と人間の役割

人間の明示開始からAIが有限対象を調査・評価・独立検証し、具体提案まで進める。最終採否とbroker操作は人間が担い、自動発注・信用・借入・空売りはしない。見送りや未確定も成果で、予算消化・投資率・銘柄数をノルマにしない。

<a id="economic-return-policy"></a>
8割勝つことを目指すが確度に固執せず、見返りに見合うリスクを取る。ならして7割勝てれば上等とし、負ける案件も含め全体の経済的利益を得る。80%/70%は保証・実測勝率・採否閾値・精密な主観確率ではない。高勝率でも少数の大損で負け得るため、投下資本・期間・損益の幅を、永久損失・集中・共通要因による同時損失と比べる。現金維持にも機会費用があり、精密な期待値を必須にせず投資と待機の双方を評価する。

永久毀損の可能性と規模を重視するが、損失ゼロを購入条件にしない。一時赤字・循環悪化・下方修正を一律除外せず、含み損や長期拘束を許容する。健全さで高値・回収不能を正当化しない。固定含み損率・金額loss budget・年間損失停止・drawdown kill switchは置かない。

評価期間は比較窓であり、保有期限ではない。持続可能な配当を選好するが無配も対象とする。通常の追加購入は既保有ticker単位で禁止し、別評価IDで迂回しない。人間が実行した追加・部分売却は事実として記帳する。

買うのは割安指標ではなく普通株主へ帰属する将来価値である。現金創出・回復・資本解放・再投資から重要な経路を選び、全方式の適用や最高評価額の採用をしない。候補viewの多さは分散の証拠ではない。調査時間は上振れだけでなく、答えが得られ判断を変えられる問いへ配分する。極端な機械順位・同じ原典の反復・戦略枠の消化を深掘りとせず、必要なら候補外対照も調べる。

<a id="required-return-policy"></a>
## 要求年率と資本

作者が案件のリスク・期間・代替案から正の有限要求年率を選び、根拠を説明する。6%は比較目安でfloor・自動値ではなく、未満も選べる。買えるまで率を下げたり期間を延ばしたりしない。変更は新評価と独立検証へ進め、過去を改変しない。[旧機械ER/FVの較正](reference/estimate-calibration.md)の固定8.5%帯とは別である。

約500万円、月40万円、10〜20銘柄は運用イメージ。通常5〜8%・1回20〜30万円のguideもquota・NAV連動sizingではない。確認済みcashとguide上限から数量上限を求め、その内側で作者が単元数を選ぶ。cash内の1単元はguide超でもwarning付き候補となり、guide下限まで増やさない。小口ではno-addにより後の増量を放棄する代償も比べる。no-addの最適性を実証したとは扱わない。

集中・ADV・cash20%等のwarningは人間へ示し、自動売却・縮小にしない。企業根拠の不足を小口やwarning受容で免除せず、予定入金・未約定売却代金・未確認時価でcash/NAVを作らない。保有は仮説不成立または確認済み残存見返り不足で回収を検討し、[継続と売却の条件](reference/trade-proposal.md#holding)に従う。

<a id="fact-analysis-separation"></a>
## 根拠と見積り

観測・規則による導出・機械見積り・AI判断を分ける。条件付きreturn/Pmaxや旧E[r]は企業scenarioの確率加重期待値・勝率ではない。確率を使うなら実測/較正と主観推定を分け、根拠・幅・感応度を示す。根拠のない精密値や言葉だけの分類を増やさない。

Baseは根拠から中心に置く条件付き経路で、常に保守caseへ寄せず、購入を通すため上振れへ付け替えない。会社計画は実現値でなく、回復・成長ゼロが常に保守的でもない。通常未達と深いstress・永久損失を区別し、Downsideを全損失の代表や最大損失保証にしない。全scenarioの黒字・要求率達成は求めず、同じリスクを利益・終価・要求率へ重複控除しない。

未知の解消を購入条件にしない。確認事実と仮定を分け、経済的影響・基準経路の根拠・反対条件・引受理由を説明できれば進める。高いBase利回りや未確認事実の捏造で不足を消さず、採否不能なら不足を限定して保留する。判定の意味は[銘柄評価](reference/stock-assessment.md#uncertainty-and-decision)へ集約する。

七つの解析モデルを企業情報と統合し、同じ価格・転載・シグナル数の多数決で判断しない。マクロは共通状態と個社への伝達、基準価値と独自仮説を分け、変化が小さくても高い調達費・借換期限を無影響としない。一領域の欠測で他を停止しない。AI等の構造変化は価値・反証・提案を変える時に扱い、利用表明や市場成長だけで利益/倍率を上げず専用score・theme枠を作らない。急落も固定の調査入口にしない。モデル追加は機会発見・比較・反証への増分価値で決め、七種を上限にも成果指標にもしない。

実績はcash・未売却損益・配当・記録済み費用/税を含む[Portfolio Outcome](../.agents/skills/ledger-record/SKILL.md#historical-outcome)で測り、個別予測・歴史較正と分ける。小標本・短期成績で戦略優位を主張しない。

<a id="development-investment-policy"></a>
## 開発・設計・レビュー

許可されたL1は広く取得・保持し、L2の精度・有用性を検証できるようにする。取得方針とL2採用を分け、AIの代替可能性や価値の推測でsource・頻度・保持を縮小しない。変更は本人の指示に基づき、障害・未確認を理由に停止を既定化しない。

共通化・自動化より先に処理をなくせないか考える。防御・監査・二重検証は実害・頻度・代替・維持費で選ぶ。稀な推測で実用化を止めず、明らかな改善へ専用実証基盤を要求しない。復元不能な本番削除は直前に対象を確認する。編集・検証の共通原則は[AGENTS](../AGENTS.md)に従う。

## 現在の非目標

機械学習score、閾値網羅探索、3か月未満のforward-backtestによるscreen最適化、ETF/投信/海外株運用、口座・税制・broker会計の完全複製、外部汎用配信・公開MCP・書込APIは持たない。長期較正は範囲内。エンジンを優先しWebへ候補抽出・判断を置かない。longfolioは別目的で連携・重複確認を持たず、投資助言サービスにはしない。
