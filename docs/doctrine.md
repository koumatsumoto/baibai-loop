# Doctrine

健全な企業の割安な機会を探し、日本個別株の現物で運用する。将来価値・価格・成立条件・確からしさ・実現時間を比べ、下落だけを割安とせず上昇中も対象にする。

<a id="investment-strategy"></a>
## 投資と人間の役割

人間の明示開始からAIが有限対象を調査・評価・独立検証し、具体提案へ進める。採否とbroker操作は人間が担い、自動発注・信用・借入・空売りはしない。見送り・未確定も成果で、予算消化・投資率・銘柄数をノルマにしない。

<a id="economic-return-policy"></a>
8割勝つことを目指し、ならして7割なら上等とするが、確度に固執せず見返りに見合うリスクを取り、負けを含む全体の経済的利益を求める。80%/70%は保証・実測勝率・採否閾値・精密な主観確率ではない。高勝率でも少数の大損で負け得る。投下資本・期間・損益の幅を永久損失・集中・共通要因による同時損失と比べ、現金維持の機会費用も評価する。精密な期待値は必須にしない。

永久毀損の可能性と規模を重視するが、損失ゼロを購入条件にしない。一時赤字・循環悪化・下方修正を一律除外せず、含み損・長期拘束も許容する。健全さで高値/回収不能を正当化せず、固定含み損率・金額loss budget・年間損失停止・drawdown kill switchは置かない。

評価期間は比較窓であり、保有期限ではない。持続可能な配当を選好するが無配も対象とする。通常の追加購入は既保有ticker単位で禁止し、別評価IDで迂回しない。人間が実行した追加・部分売却は事実として記帳する。

買うのは割安指標でなく普通株主へ帰属する将来価値。現金創出・回復・資本解放・再投資から重要な経路を選び、全方式適用/最高評価額採用をしない。候補viewの多さを分散とせず、調査は上振れだけでなく答えが得られ判断を変える問いへ配分する。極端な機械順位・原典反復・戦略枠消化を深掘りとせず、必要なら候補外対照も調べる。

<a id="required-return-policy"></a>
## 要求年率と資本

作者がリスク・期間・代替案から正の有限要求年率を選び説明する。6%は比較目安でfloor/自動値でなく、未満も選べる。購入を通すため率を下げたり期間を延ばしたりせず、変更は新評価・独立検証へ進める。[旧機械ER/FV較正](reference/estimate-calibration.md)の固定8.5%帯とは別で、過去は改変しない。

約500万円・月40万円・10〜20銘柄は運用イメージ。通常5〜8%・1回20〜30万円のguideもquota/NAV連動sizingではない。確認済みcashとguide上限から数量上限を求め、その内側で作者が単元数を選ぶ。cash内の1単元はguide超でもwarning付き候補とし、下限まで増やさない。小口とno-addで後の増量を放棄する代償も比べ、no-addを実証済み最適策としない。

集中・ADV・cash20%等のwarningは人間へ示し、自動売却/縮小にしない。小口/warning受容で根拠不足を免除せず、予定入金・未約定売却代金・未確認時価でcash/NAVを作らない。保有は仮説不成立または確認済み残存見返り不足で[回収を検討](reference/trade-proposal.md#holding)する。

<a id="fact-analysis-separation"></a>
## 根拠と見積り

観測・規則による導出・機械見積り・AI判断を分ける。条件付きreturn/Pmaxや旧E[r]は企業scenarioの確率加重期待値/勝率ではない。確率には実測/較正と主観推定の別、根拠・幅・感応度を示し、根拠のない精密値や言葉だけの分類を増やさない。

Baseは根拠から中心に置く条件付き経路で、常に保守caseへ寄せたり購入を通すため上振れへ付け替えたりしない。会社計画は実現値でなく、回復/成長ゼロが常に保守的でもない。通常未達と深いstress・永久損失を分け、Downsideを全損失の代表/最大損失保証にしない。全scenarioの黒字・要求率達成を求めず、同じリスクを利益・終価・要求率へ重複控除しない。

未知の解消を購入条件にせず、[根拠・受容理由・保留条件](reference/stock-assessment.md#uncertainty-and-decision)で判断する。

七モデルを企業情報と[統合](reference/stock-assessment.md#analysis-domain-integration)し、同じ価格・転載・signal数の多数決で判断しない。マクロは共通状態/個社への伝達、基準価値/独自仮説を分け、変化が小さくても高い調達費・借換期限を無影響としない。一領域の欠測で他を停止しない。AI等の構造変化は価値・反証・提案を変える時に扱い、利用表明/市場成長だけで利益/倍率を上げず専用score・theme枠を作らない。急落を固定入口にせず、モデル追加は発見・比較・反証への増分価値で決め、七種を上限/成果指標にしない。

実績はcash・未売却損益・配当・記録済み費用/税を含む[Portfolio Outcome](../.agents/skills/ledger-record/SKILL.md#historical-outcome)で測り、個別予測・歴史較正と分ける。小標本・短期成績で戦略優位を主張しない。

<a id="development-investment-policy"></a>
## 開発・設計・レビュー

許可されたL1を広く取得・保持しL2の精度/有用性を検証する。取得方針とL2採用を分け、AI代替可能性/価値の推測でsource・頻度・保持を縮小しない。変更は本人の指示に基づき、障害・未確認を理由に停止を既定化しない。

共通化/自動化より先に処理をなくせないか考える。防御・監査・二重検証は実害・頻度・代替・維持費で選び、稀な推測で実用化を止めず、明らかな改善へ専用実証基盤を要求しない。復元不能な本番削除は直前に対象を確認する。編集・検証は[AGENTS](../AGENTS.md)へ。

## 現在の非目標

機械学習score・閾値網羅探索・3か月未満のforward-backtestによるscreen最適化、ETF/投信/海外株運用、口座/税制/broker会計の完全複製、外部汎用配信・公開MCP・書込APIは持たない。[旧方式の再生成](architecture.md#store-authority)はせず、Webへ候補抽出・判断を置かない。longfolioは別目的で連携/重複確認を持たず、投資助言サービスにはしない。
