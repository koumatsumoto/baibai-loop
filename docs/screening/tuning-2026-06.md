# 戦略チューニング記録 (2026-06)

selection の構造変種を replay(tune: 2026-05-08/05-15、holdout: 05-29)で計測し、旧記録 root(05-01 を含む 4 週、チューニング未使用)で外部検証した。採用条件は (a) tune 改善 (b) holdout 非劣化 (c) メカニズム説明可能、の 3 つ。閾値の grid search は行わず、有限の構造選択のみを比較した。

## 判別不能として記録した仮説

- fast_dislocation の閾値プロファイル・stabilization の強条件・regime 閾値の変種は、評価可能な全週が `risk_on_rally`(fast boost 中立化)のため queue レベルで判別できない。selloff / neutral 週の forward が蓄積した時点で再計測する
- 決算近接の除外は平均リターンでなく分散に効く仮説のため、本計測系では判定しない

## 結論

現行構成(regime lens / lane 順序 config 正本 / `selection.liquidity` / stabilization / balanced・top5)が、計測した全変種に対して 2 つのデータ root と外部検証で優位。次回のチューニング再開条件は forward データの蓄積(2026-07 以降、#157 と同時期)。
