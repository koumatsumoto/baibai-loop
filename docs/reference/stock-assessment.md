# Stock Assessment

[doctrine](../doctrine.md)に沿う企業理解・価値・反証・独立検証の意味を扱う。操作は[skill](../../.agents/skills/investment-judgment/SKILL.md)、現在価格/cashへの適用は[提案](trade-proposal.md)へ。

## 観測と根拠

入力・出典は[固定保存](../architecture.md#store-authority)と[時点・欠測](model-observations.md#source-owners)に従う。機械ER/FVは転記せず、価値計算に選ぶ価格は未調整1株basis、日次終値に架空時刻を付けない。分析用の調整後価格は元basisのまま観測として残せるが、価値計算の価格へ選ばず、未調整価格へ言い換えない。

新規Research・Assessmentで時刻付きの価格観測は少なくとも一つの引用取得以前とする。日付だけの終値は、新規の保存・評価時点を日本時間で見て、その日の所定の引け時刻より前なら前日、以後なら当日を上限とする。日付だけの終値には、引用の取得時点でもこの上限を満たす出典を少なくとも一つ求める。休場日を含め、実際の取引日かどうかは照合せず、観測時刻も補わない。記録整合の検査でprovider時計/価格の真偽を証明せず、保存済みResearch・pairの読取・同内容再送を再判定しない。

新規の派生比率は、計算断面のas_ofを参照Factの日付より前に置かない。入力同士の同日性は要求せず、会計期間・連結scopeの比較可能性は原典とReviewで確認する。保存済みpairの日付・hashは変更しない。

一次性と企業からの独立性は別。EDINET/TDnet/JPX配布の会社資料もissuer-primaryで、転載・sponsor調査・同じpress kitは独立票でない。顧客/競合資料は直接知る範囲を支持する。実績と将来計画/因果を分け、採否を変える需要・優位性・外部状態・pipeline成功には独立根拠を求める。全記述へ2 sourceを課さず、会社計画の割引を独立見積りとしない。

[既存のResearchと評価を再訪する](../../engine/src/baibai_engine/investment_judgment/company_research/query.py)ときは、仮説・支持/反証/未解決・資料日/取得日・独立Reviewの確認範囲を、同じ元記録から読む。最初の表示は全件でも重要度順でもない。切れた文、表示外の反証・問い・引用は元のIDで確認する。同じ資料を異なるIDで引用しても独立した裏付けにならず、資料の取得日は次回予想の対象期でもない。

当時の価値実現の機序・時期・遅延理由、何が最も強い反証だったかを今回の問いに使う。確認者の対象出典と作者の仮説を混ぜず、未記録を反証なしとしない。過去に「同じ権利なら別価格で再検討」とした場合は、当時の株式単位・取得期限・事業前提を確認する。価値が未確定なら、どの期間のどの開示が一株の回収額を変えるかを調べる。以前のstance・Pmax・売買結果・経過した期間から現在の割安判断を復元しない。

Researchからの下書きに含まれる仮説・引用・調査範囲は当時の未採択素材。今回も成立する理由・反対材料・未確認範囲を評価本文へ反映し、独立Reviewを受ける。下書きの参考コメント自体は証拠ではない。

競合は同じ顧客・サービス・地域での競争と、地域同業・上場代替投資を分ける。同じ料率表は同じ実効単価/採算を意味せず、非上場の直接競合へ別事業の上場倍率を移さない。企業文化は公式理念、制度/投資/事故等の行動、結果を対象範囲と日付付きで照合し、長い歴史や安全宣言を独占・無事故・株主利益の保証にしない。取得日を内容更新日へ置き換えない。

単一事例を一般化せず、非開示/検索不発を不存在としない。裏取り不能/矛盾は試したsourceと影響を残す。既存事業価値で成長仮説を支持せず、重要な肯定的主張を無条件にBaseへ入れない。幅が狭まらなければ反復を止め、[受容理由と再評価条件](#uncertainty-and-decision)を残す。

<a id="recent-news-research"></a>
### 直近ニュース・カタリスト

価格急変によらずcutoff以前の公式IR・適時開示・企業/サービス告知・信頼できる事実報道を実検索する。前回差分と重要な継続案件、初回は最新決算等から範囲/空白を示す。固定短期窓・好悪件数合わせ・無変化の全文再調査は不要。

snippetから原文へ戻り、法人/上場親子、発生/発覚と公表、訂正を確認する。事実・会社見解・報道・推論と検索範囲/重要な未確認/出典を残し、利益・cash・追加資本・回復期間への影響または判断不変の理由を仮説/最強反証へ結ぶ。価格無反応を無影響/織込済みとしない。

<a id="event-resolution"></a>
予定開示を待っていた対象の再訪では、原典の掲載・延期・訂正と、判断に効く同時期の関連開示も確認する。日付経過だけで実施済みとせず、決算本文だけで配当・資本配分の変更を読み終えたとしない。解消した問い・一部判明・残る不明を分け、古い「発表待ち」を今回の待機理由へ複写しない。過去の待機判断を遡及して誤りにせず、新しいResearch/評価で残る問いと価値・価格・待機への影響を更新する。

概算・申請額・対象範囲内の上限と最終負担、保険/助成の上限と確定回収、一時費用と継続費を分ける。予想据置は影響精査中の場合もあり、無影響の証明ではない。投資計画の縮小は時期・仕様・代替投資を伴い得るため、差額を自由な株主cashにしない。配当方針は適用期・算定基準・条件を読み、目標を支払保証や分配能力の確認へ変えない。全額確定を一律に待つのでなく、重要な幅と必要資金を[受容理由](#uncertainty-and-decision)へ結び、経済判断の未完成と出典の未確認を区別する。

## 経済性から問いを選ぶ

抽出理由と株主へのcash経路を分け、結論を左右する問いを選ぶ。複合事業は接続し、全問checklistにしない。

- 契約・人員projectは更新/解約・単価/usage・獲得/提供費・稼働・賃上げ/育成・検収/回収・不採算を問う。ARR/受注残/契約負債を混ぜず、未開示KPIを創作せず、受注/採用を同marginの即時売上にしない。
- 有限権利は減衰・寿命・更新/撤退費・stage/成功、市況事業は数量/価格/mix・在庫/ヘッジの期/表示・運転資金・維持/成長投資を問う。償却足戻しで寿命を延ばさず、反転時は利益と資金を共に動かす。
- 資産/複合は連結scope・親持分・[帰属/拘束/他請求](#capital-bridge)と税/換金費・分配主体/時期、売却/回復は利益と入金・税/返済・残存事業・期間/追加資本を問う。一時利益と共に一回の資本改善まで消さない。
- 金融は再価格化・調達/信用費用・留保後ROEを問い、金利方向だけで受益認定しない。

共通して利益の反復性・3FY平均の循環代表性と追加投資の限界収益を問い、過去capital proxy/会社ROIC目標を新規投資収益率にしない。KPIの期間・分母・定義変更・M&Aを揃える。

<a id="analysis-domain-integration"></a>
## 解析モデルの統合

[統合方針](../doctrine.md#fact-analysis-separation)に従い、[七モデル](../architecture.md#現在の解析モデル)の重要な支持・相反・不足を個社仮定へ結ぶ。

まず採否を動かす「事業の変化 → 利益・追加資本/資金 → 普通株主へのcash・価値 → 価格条件」の経路を、既存の仮説・計算・投資理由として組み立てる。候補に選ばれた理由は入口であり、調査後も同じ価値経路を採るとは限らない。七観点の表示はこの統合判断を分解して説明するもので、個別の評価を平均して総合判断を作らない。

補完関係は同じscenarioの中で扱う。増収と運転資金/借入増、海外の利益率改善と非支配持分、設備投資と将来収益のように一つの要因が複数箇所を動かすなら、単変量の感応度だけでなく、重要な上下の組合せを同じ期間・帰属で比べる。全変数の最悪化や全組合せの探索は不要。数量を小さくしても一株の価値や未解決の資金条件は改善せず、資本配分と待機の比較は[提案](trade-proposal.md#limit-selection)で行う。

<a id="segment-profit-bridge"></a>
**主力成長と全社利益をつなぐ。**

主力の成長と全社減益が併存するなど、内訳が価値判断を変える時は、同じ期間・会計範囲のセグメント利益から全社費用/消去を経て全社営業利益へ照合する。増分のうち数量/単価・事業構成、継続費用、一時要因、投資の前倒し/後ずれを分け、主要な差額を出典付きで既存の所見・計算へ残す。全事業の精密な分解を待たず、未開示部分は総額との残差と幅で扱う。主力だけを取り出した利益や、全社費用を二重控除した利益を株主価値に使わない。

その橋渡しから、主力の増分が必要費用と追加資本を吸収するBase/Downsideを組み立てる。費用を一時的とするなら終了条件、成長投資とするなら収益化の時期と必要資金を明らかにし、四半期利益の単純年率化より持続可能な利益の幅を使う。事業売却/取得は残存利益・回避費用と対価/税/負債を分け、最後に[普通株帰属](#capital-bridge)へつなぐ。独立Reviewは最大の差額とその継続性を反対側から確かめ、次に判断を変える一つの観測を選ぶ。これは既存の評価を具体化する手順で、新しい必須項目や購入gateではない。

七観点について作者の判断を残すときは、評価本文の任意の `model_perspectives` に個社への意味・出典・重要な期間や範囲を記す。支持・相反併存・逆風・中立・情報不足・対象外は説明であり、買いの票ではない。未取得や比較不能は、何を調べて何が足りなかったのかを示し、中立や対象外に置き換えない。L2外の一次資料を使った場合も区別する。新規の雛形には七観点の欄があるが、埋めた行数は購入条件ではない。

[正式提案のWeb表示](../../web/README.md#提案レポートの読み方)は、作者が記録した観点を「情報不足」「対象外」も含めてそのまま示す。作者が記録していない観点では、発行時の選定原本から読める範囲を「固定資料の観測」として別欄に示す。評価の新旧に関係なく、これは元評価への追記ではない。作者の判断を変えるには新しい評価と独立Reviewが必要である。

価値と市場評価のずれは、同じexact評価の`findings.value_gap_explanation`を最終提案にも全文で表示する。観点別summaryへの複写は要求せず、比較不能や独立予想でない旨も残す。添える出典は調査所見全体の参照で、全ての記述を各資料が支持するという対応を捏造しない。旧表示JSONの欄欠落を「ずれがない」とせず、現在の外部予想で保存説明を更新しない。

- [会計比較](model-observations.md#financial-periods)に従い年間/直近同四半期を読む。前年を正常値とせず回復は履歴で確認し、報告増を有機成長と即断しない。営業CF低下≠正常FCF悪化、利益/EPS/低PER≠独立票で、科目不足なら原典へ戻る。
- [環境・外部評価](model-observations.md#external-assessment): 需要/費用/資金と要求収益/織込み/流動性への伝達を分け、一致/相違を元仮定へ戻す。同年度/定義の総額予想−累計実績は必要残額で実現確率ではない。取得日を全予想の更新確認とせず、株式basis不足で総額比較まで禁じない。
- [産業/社会](../architecture.md#現在の解析モデル): 母集団・期・利益basisと主張の帰属/範囲/条件を保ち、重要原文をexact参照する。黒字企業割合≠利益率、原典/抽出訂正≠実変化、倒産/譲渡≠供給消滅。予定日経過を実施、coverage/省略を変化なしとせず、個社への伝達はL3仮説とする。
- [テクニカル](model-observations.md#technical-analysis): 価値実現期間と価格窓を分け、重要なら同refの市場/業種比較と[ニュース](#recent-news-research)で競合仮説を検討する。単純差≠alpha/原因で、価格局面だけでPmax/売買条件を変えない。

外部変化は関係する製品・顧客・地域を確かめ、数量/単価/費用・cashのどこへ、いつ届くかを既存の事実・仮説・計算へ結ぶ。例えば原油現物価格と船舶用燃料の油種/地域/通貨は異なり、ヘッジ・使用量・料金転嫁の参照期間と適用期間を通して負担を考える。港湾の貨物量・入港隻数・総トン数は別の観測で、特定企業の受注件数/作業時間や市場shareへ直結させない。同じ統計や会社発表の転載を裏付けの追加とせず、判断を変える次の一観測を選ぶ。

全指標/注記やマクロ固定起点を要求せず、価格と事業を往復し過度な悲観・一時悪化も検証する。事後比較を旧snapshotの根拠や候補外発見/長期収益優位の証明にしない。

<a id="scenario-arithmetic"></a>
## 条件付き価値

新しい評価は、これから普通株を取得する人のどの権利・期限について、**当時の観測価格に照らして割安の根拠があるか**を一度だけ記す。価格と両立し得る事業・権利条件を、価格自体とは独立した一次資料の経済事実および投資理由・反証と比べる。固定給付や資産の回収に継続事業のDCFを強制しない。給付額・残余株主への分配・権利落ち等の事実は株価や倍率からは証明できない。調査したが未確定、根拠を比べて不支持、当時未記録は別。事業仮説の支持・合計利回り・個人資金から割安を推定しない。

不支持でも、権利・事業の前提を変えず価格だけで覆るなら、その理由と必要に応じ同じ一株の検討上限を残す。計算上のPmaxはこの根拠を生成しない。文章条件は注文指値にならず、上限を満たしても口座・発注可否とは別。給付の受取資格が割安判断を左右する場合のみ、同じ権利を取得できる最終立会の一次事実に結ぶ。支払日や権利確定日と混同しない。最終立会が未定なら未定とし、次の立会で取得できるとみなさない。刷新では原判定を持ち越さず、当時の未調整価格・権利の継続を確認する。独立Reviewは値の一致だけでなく普通株への帰属、取得者、期限、価格以外の証拠と反証を照合する。

resolvedは原価格・期間・要求率・Base/Downsideの単位・利益・資金・帰属と仮定の整合で、将来確定ではない。unresolvedは理由を残しゼロ/推定で埋めない。要求率は[資本方針](../doctrine.md#required-return-policy)、Base/Downsideは[見積り方針](../doctrine.md#fact-analysis-separation)に従う。

terminalは分配後の残余価値、cashは期間内累積分配。同じ起点の未調整1株に揃え、配当・売却・買戻しを重ねない。権利落ち後価格と未入金配当権利を分け、権利確定前の未公表配当は仮定とする。年率は投資家の税費用前・分配再投資なしで期待値/IRRではない。企業利益の税/営業費用は除かない。算式は[scenario](../../engine/src/baibai_engine/investment_judgment/stock_assessment/scenario.py)が所有し、表示丸めで判定しない。

<a id="valuation-model-choice"></a>
### modelと期間

[価値獲得経路](../doctrine.md#investment-strategy)から選び、株価へ合わせたり全方式を平均したりせず、EPS×PER・12か月を既定にしない。費用・追加資本・帰属・時期を揃え、費用化済み人材/R&Dを再控除せず、倍率内の成長/再投資と別認識資産を分ける。利益倍率へTTMを採るなら構成した全期間の重要な一時損益を確認し、算術の`exact`を反復利益の認定にしない。

留保で簿価が増えるPBR一定とPER一定は別。終期利益・簿価・分配を揃え、倍率が上昇する/しない両経路を検討し、Downsideを無関係な全変数の最悪化にしない。複数年は中間の事業・投資・資金も記し、期間延長で分配だけ増やさない。早期分配が採否を変えるなら感応度を示し、modelを変える観測条件を残す。

低PBRと低収益が併存するときは、資産回収・利益回復・還元・市場倍率変更のうち価値が届く経路を比べる。資産バスケットは簿価へ加算する額でなく代替評価とし、総額/引当金・税/必要資金・非支配/持分法の帰属を揃える。会社の資本政策の意向、決議、実行と作者の回収率/終期倍率を既存の事実・仮説・計算へ分け、政策公表や全未知の解消を購入条件にしない。

<a id="capital-bridge"></a>
### CFと終期資本

銀行の預金流入や貸出増、保険・証券等の顧客資金は、普通株への分配・毀損ではない。報告営業CFから設備取得を引いた比率の `exact` は期間・算術の品質で、株主利回りの確度ではない。銀行は政策保有株売却の税後額・信用費用を分けた継続利益を、その銀行が必要とする資本（[適用される規制](https://www.fsa.go.jp/policy/basel_ii/)に応じたCET1・国内基準のコア資本等）・経営バッファ・再投資と突き合わせ、残る普通株への実分配・成長を価格に照合する。含み益込みの規制資本に売却益を重ねない。保険は支払余力、複合金融は事業別制約を調べ、不明は一般企業と仮定しない。

重要な留保CFは、期首→期末のcash・非営業資産・負債・非支配請求を営業CF・投資/運転資金・分配/返済/増資・終期株数へ同期間/単位で橋渡しする。連結資産/預り金を普通株主余剰にしない。持分法投資が重要なら、持分損益、投資先から出資会社への配当入金、上場会社から普通株主への分配を分ける。配当決議や利息・配当の受取合計から個社分の入金を決めない。投資を別に値付けするなら同じ持分利益・運用益を含む倍率評価に重ねず、未分配だけで持分を無価値にもしない。

利益と営業CFで値付けが変わる場合は、まずそれぞれの対象期間を確かめる。直近四半期にCF表がなければ、原表で期間・連結範囲・会計基準を照合し、比較できる直近12か月（前期通期＋今期累計－前年同期累計）をその**実際の終点**で示す。揃わない期は埋めない。複数年と比べる際も、有形・無形の現金取得は維持と拡張を含み得る。リース元本・他の持分への支払いが未区分なら、差引後の普通株主手取りまで確認したことにしない。

次に、価格との比較を反転させる資金の動きを一つ選ぶ。前受契約なら未履行サービス、決済代行なら未収・未払・預りの差額、小売なら休日を挟んだ仕入代金の支払いなど、入金とそれに伴う義務を組にして原表を読む。報告どおりの額、期首・期末の注記で特定できたずれだけを直した額、その要因全体を一定と仮定する感応を区別する。12か月の途中の決算日をもう一度調整しない。どの金額・いつの開示で判断が変わるかを残す。全額が一時的と決めず、一律の連続黒字・CF足切りにはしない。

- EVに含む必要操業cashだけを別cashから控除し、不足をmax(0, ...)で消さない。NI×PERの株主価値へ全cashを足す/負債を再控除することはしない。差引済み税・利息・投資も重ねない。一時損益はPL・CF・期末残高の既処理を揃え、CFで調整済みの売却益を再控除したり、残高に入った売却収入を再加算したりしない。
- 返済はcash/debt双方、買戻しはcash/株数双方、増資は調達額/分母双方を動かす。分配停止時のcashを消さず、新規払込を既存株主の価値創出にしない。優先株がある場合はEPS注記の普通株帰属額を確かめ、優先配当の帰属・現金支払・相殺を区別する。転換後に旧優先控除を延長せず、新しい普通株数と同じ時点の自己株で起点1株の権利を測る。
- 未コミットM&Aを実行済みにせず、織込むなら対価/調達と取得価値を揃える。賃借料とリース負債を二重控除せず、会計変更を成長としない。非現金費用の足戻しは消耗不存在を意味せず、CF反映済みなら重ねない。
- 金融のcash−debtを余剰株主資産とせず、規制資本・普通株主資本・OCI・分配可能性を分ける。

<a id="draft-calculation"></a>
### 計算資料

`investment-judgment calculate`の[入力契約](../../engine/src/baibai_engine/investment_judgment/stock_assessment/calculation.py)はtyped ratio/Projectionで、文章/売上からterminalを作らない。任意の別価格比較は観測Factを替えず同じ評価起点/horizonを使い、待機後の残期間や未約定を扱わない。仮数量の損益は全量同値成立・税費用前・再投資なしの条件例で、支出を口座cash/購入可能量にしない。単元・呼値・約定・採用/Reviewは検証せず、元の評価/Review算術や正規提案のPmax/no-addを変えない。

計算/現在価格比較の二ケース損益分岐は、BaseとDownsideだけが全結果であると仮置きし、同じ起点一株・終期の価値＋累積分配を混合するBase重みの条件を示す。実際の確率・期待リターン・勝率や採否閾値ではなく、他の結果や深い損失もあり得る。無利息cashと同額になる条件と、作者要求年率の終期相当額に達する条件を分け、年率を平均しない。分配は一度だけ数え再投資せず、税・売買費用・spread/impactを含まないため、それらや期間・権利が異なる案を同じ分岐で比べない。未採択/比較不能なケースから数値を補作せず、二ケースの同値・逆順や達成不能を架空の0〜100%へ丸めない。Pmax・数量・gateや保存評価を変えず、重みの観測根拠がないまま購入根拠にはしない。

比率へ使う明示した発行済み株数は、減少量や別単位と残高を混同しない。計算に使わない欠測・原単位のFactまで削除させず、0の観測と0で割ることも分ける。損失や符号付きの一般比率は禁止しない。普通株への帰属・自己株・期の整合は引き続き原典とReviewで確認し、旧保存の読取を新しい入力審査へ変えない。

`--cash-share-cb`は額面現金＋転換価値超過分の株式交付CBだけの試算。額面は計上債務の消滅と対応し再控除しない。決済VWAP・配当調整参照終値・評価株価、端株現金をVWAPと置く試算・VWAPと終価を結ぶ固定点を分ける。調整時期/本数/権利は原典確認し、連続近似や整数固定点不存在を実決済へ読み替えない。採否は別判断である。

<a id="valuation-context"></a>
### 原価格の成立条件

[Pmax](trade-proposal.md#条件付き購入)の必要値を利益・必要資本・分配の同時成立経路と照合する。独立signal/市場予想やDownside不足の追加gateにしない。価値固定の延長では年率損失が縮んでも損失額は減らず、実遅延はcountercaseへ反映する。

<a id="permanent-loss-axes"></a>
## 永久損失

資金余力・返済・CF・希薄化・顧客集中・構造的衰退・governance/accountingの7軸を調べる。確認済み曝露を規模/確率未確定のためunknownへ戻さない。verifiedは記した根拠の確認範囲で、安全保証ではない。赤字/下方修正だけで永久損失とせず、引受根拠不足を小口/overrideで通さない。

<a id="uncertainty-and-decision"></a>
## 不確実性を引き受ける判断

過去のreview済み評価を再訪する際は、最強反証に加え当時の投資仮説の破綻条件を読む。初回表示は有限の抜粋なので省略・切詰めがあればexact評価へ戻り、条件を現在満たしたかは後日事実と別に検証する。条件の存在だけで仮説をbrokenにせず、旧Selectionへ現在の条件を後補完しない。

仮説は未破綻（intact）、仮説/中核根拠の整理不足で評価未完（uncertain）、不成立（broken）を分ける。将来利益率等の未確定だけでuncertainにせず、別の再建/回収仮説は検討できるが、反証された旧仮説を安さで復活させない。

supportedには未破綻以上の積極的な価値根拠が必要。不明点と利益/資金/希薄化/価値への影響、Baseを選び見返りで引き受ける理由を所見・計算・最強反証へ結び、損失記載だけで受容済みにしない。未開示の顧客別採算等は総額/妥当な仮定で評価できるが、根拠/代替のない借換成功を高利回りや架空事実で通さない。採否不能なら不足を限定して保留し、観測価格・単位・期間を創作しない。supportedは購入採用と別で、Pmax超過やquote/cash不足をunsupportedにしない。

機械検証は構造・参照・算術・説明欄を確認するだけで、経済的妥当性は作者と独立検証が判断する。旧`nonmaterial_unknown_reason`の受付を、当時の重要リスク受容審査へ読み替えない。

<a id="independent-second-pass"></a>
## 独立検証と保存

別作業者が原典・上流算式・当期/前期見出し・単位/期間・仮定/最強反証を確認する。resolvedのterminal/cashは独立入力から再計算し、unresolvedは所見・不足・結論を検討する。抽出値/出力コピーや誤入力/hash一致を独立性/真実性の証明にしない。[資本の橋渡し](#capital-bridge)、過大/過小仮定、相反/比較不能・unknown/partial・受容理由と検証限界を残す。

評価/ReviewとProposalは同じexact core pairへ束縛する。最新のunsupported/unresolvedを避けて旧supportedへ戻らず、保存読取へ現在cash/価格条件を適用しない。

保存提案には同じReviewが確認対象とした資料とその時計を、作者引用とは別に表示する。確認対象の記録を全記述の検証・資料間の独立性・現在の確認へ広げず、一次資料の確認状態・検証範囲・残る不確実性と併読する。旧表示の未収録を作者引用や全資料から補わない。

<a id="assessment-refresh"></a>
## 差分refreshと文章編集

同日pairは再利用できる。翌日以降の当日算術は価値・開示・仮説・株式単位・[残期間/今後分配](trade-proposal.md#holding)を差分確認し新Reviewへ束縛する。素材prior/最新supersedes先とsource/fact日付を保ち、全資料再取得や旧12か月の延長はしない。整数月≠厳密残日数で、現在projection不可でも旧原価格算術は読める。保存提案の表示にも、そのexact評価の差分確認と更新元素材を残す。後発評価へ差し替えず、更新元素材を当初購入理由・現在の再確認へ読み替えない。

新規refreshの公開では、元exact素材から変えた既存の所見・価値・投資理由・リスク・出典・モデル観点を変更区画へ申告する。変更区画の列挙はReview範囲を誤らせないための照合であり、変更の妥当性・重要性や申告外の全文確認を代替しない。広めの申告は許容し、旧保存の読取・同内容再送へ新しい申告要件を適用しない。

編集は数値・単位・日付・比較基準・支持/反証・限定をtitle/summaryまで保つ。同文を各欄へ複写せず、材料→仮定→比較理由へ辿れるようにする。新根拠/因果/判断は変更部分と下流を再Reviewする。
