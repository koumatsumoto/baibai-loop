# Stock Assessment

企業理解・価値・反証と独立検証を保存する。採否方針は[doctrine](../doctrine.md)、現在価格/cashへの適用は[Trade Proposal](trade-proposal.md)、取引は[Ledger](../../.agents/skills/ledger-record/SKILL.md)、操作は[skill](../../.agents/skills/investment-judgment/SKILL.md)が所有する。

## 観測と根拠

入力・出典を固定し、元generation/旧runの存続や機械ER/FVの重複転記を要求しない。価格は未調整1株basis。財務対象期・予想対象期と公表/提出日を分け、日次終値へ架空時刻を付けず、後発資料を当時既知にしない。

一次性と企業からの独立性は別である。EDINET/TDnet/JPX配布の会社資料もissuer-primary。転載・sponsor調査・同じpress kitを独立票にせず、顧客/競合資料もその主体が直接知る範囲だけを支持する。公表実績の確認と将来計画・因果の裏取りを分け、採否を変える需要・優位性・外部状態・pipeline成功には独立根拠を求める。全記述へ2 sourceを課さず、会社計画の割引を独立見積りとしない。

単一事例を市場へ一般化せず、非開示・検索不発を不存在にしない。裏取り不能/矛盾は試したsourceと影響を残す。確認済み事業の価値と元の成長仮説の支持は別であり、重要な肯定的主張を無条件にBaseへ入れない。追加調査で幅を狭められなければ同じ検索を反復せず、[受容理由と再評価条件](#uncertainty-and-decision)を残す。

<a id="recent-news-research"></a>
### 直近ニュース・カタリスト

価格急変の有無によらずcutoff以前の公式IR・適時開示・企業/サービス告知・信頼できる事実報道を実検索する。前回以降の差分を中心に重要な継続案件へ遡り、初回は最新決算等を起点に範囲と空白を示す。短い固定窓・好悪の件数合わせ・新材料のない全文再調査は不要。

snippetから原文/一次情報へ戻り、法人・上場親子、発生/発覚と公表日時、訂正を確認する。事実・会社見解・報道・推論を分け、検索範囲・重要な未確認と出典をsources/findingsへ残す。利益・cash・追加資本・回復期間への影響または判断不変の理由を仮説/最強反証へ結ぶ。価格無反応は無影響・織込済みの証拠ではない。

## 経済性から問いを選ぶ

抽出理由と企業が稼ぎcashを帰属させる経路を分け、結論を左右する問いだけを選ぶ。複合事業は接続し、全問checklistや分類fieldを増やさない。

| 経路 | 確認する違い |
| --- | --- |
| 継続契約 | 更新/解約・単価/usageと獲得/提供費用。ARR・受注残・契約負債を混ぜず、未開示NRR/CACを創作しない。 |
| 人員project | 単価・稼働・賃上げ/育成・検収/回収・不採算。受注/採用を同marginの即時売上にしない。 |
| 有限権利/IP | 収益減衰・権利期間・更新/撤退費・stageと成功。償却足戻しで寿命を延ばさない。 |
| 市況/加工 | 数量/価格/mix・在庫/ヘッジの期と表示位置・運転資金・維持/成長投資。反転時は利益と資金を共に動かす。 |
| 資産/複合 | 連結scope・親持分/他請求権・拘束・税/換金費・分配主体/時期。連結資産や預り金を株主余剰にしない。 |
| 金融 | 再価格化・調達/信用費用・OCI・規制/普通株主資本・留保後ROE。金利方向だけで受益認定しない。 |
| 売却/回復 | 利益と入金・税/返済・残存事業・期間/追加資本。一時利益と共に一回の資本改善まで消さない。 |

利益の反復性、3FY平均の循環代表性、資産の帰属/回収、追加投資と限界収益を問う。過去capital proxy・会社ROIC目標を新規投資収益率とせず、KPIの期間・分母・定義変更・M&Aを揃える。

<a id="analysis-domain-integration"></a>
## 解析モデルの統合

[七モデル](../architecture.md#現在の解析モデル)の重要な支持・相反・不足を個社仮定へ結ぶ。全指標の消化やマクロ固定起点を要求せず、価格と事業の不一致から往復する。悪材料だけでなく過度な悲観・一時悪化も検証する。

- [成長](model-observations.md#financial-periods): 年間水準と直近同四半期を読む。前年を当然の正常値とせず、回復継続は履歴で確認する。報告増を有機成長、営業CF低下を正常FCF悪化と即断せず、利益/EPS/低PERを独立票にしない。科目不足で原典調査を止めない。
- [環境・外部評価](model-observations.md#external-assessment): 需要/費用/資金と要求収益/織込み/流動性への伝達を分ける。相違も一致も元仮定へ戻る。同年度/定義の総額予想−累計実績は必要残額で、実現確率ではない。取得日だけで全予想を最新決算反映済みにせず、株式basis不足を総額比較禁止へ広げない。
- 産業/社会: 市場・母集団・期・利益basisを保持し、黒字企業割合≠利益率、変化≠原典/抽出訂正、倒産/譲渡≠供給消滅。発表者・範囲・否定・条件・予定を保ち、予定日経過を実施確認にしない。coverage/省略を変化なしとせず、重要原文をexact参照する。個社への伝達はL3仮説である。
- [テクニカル](model-observations.md#technical-analysis): 価値実現期間と価格窓を分ける。重要なら同refの市場/業種比較で期間と競合仮説を選び、[好悪ニュース](#recent-news-research)から利益・cash・必要資本への影響を問う。単純差はalpha/原因同定ではなく、価格局面だけでPmax/売買条件を変えない。旧snapshotへ後付けせず、全注記の消化を求めない。

一領域の欠測や事後比較を、全体停止・当時判断の根拠・候補外発見や長期収益優位の証明にしない。

<a id="scenario-arithmetic"></a>
## 条件付き価値

resolvedは原価格・期間・[案件の要求率](../doctrine.md#required-return-policy)・Base/Downsideが、根拠付き仮定の下で単位・利益・資金・帰属と整合すること。将来確定ではない。unresolvedは理由を残し、未確定値をゼロや推定で埋めない。

terminalは分配後の残余価値、cashは期間内累積分配で、同じ起点の未調整1株へ揃える。配当・売却・買戻しを二重算入せず、権利落ち後価格と未入金配当権利を分ける。権利確定前の未公表配当は仮定である。[算術owner](../../engine/src/baibai_engine/investment_judgment/stock_assessment/scenario.py)の年率は投資家の税費用控除前・分配再投資なしで、期待値/IRRではない。企業利益の税/営業費用を除く意味でもなく、表示丸めで判定しない。

<a id="valuation-model-choice"></a>
### modelと期間

株価に合わせず価値獲得経路から選ぶ。EPS×PER・12か月を既定にせず、全方式平均/最高値選択をしない。持続利益/cash、回復/再投資、有限寿命/資本解放ごとに費用・追加資本・帰属・時期を揃える。費用化済み人材/R&Dを再控除せず、倍率に含む成長/再投資と別認識資産を分ける。

留保で簿価が増えるPBR一定とPER一定は異なる。終期利益・簿価・分配を揃え、倍率上昇の根拠と上昇しない経路も検討する。Downsideを無関係な全変数の最悪化にしない。複数年では中間の事業・投資・資金もcalculationへ記し、延長で分配だけ増やさない。早期分配が採否を変えるなら感応度を示し、modelを変える観測条件を残す。

<a id="capital-bridge"></a>
### CFと終期資本

重要な留保CFは期首→期末のcash・非営業資産・負債・非支配請求と、営業CF・投資/運転資金・分配/返済/増資・終期株数を同期間/単位で橋渡しする。

- EVに含む必要操業cashだけを別cashから控除し、不足をmax(0, ...)で消さない。NI×PERの株主価値へ全cashを足す/負債を再控除することはしない。差引済み税・利息・投資も重ねない。
- 返済はcash/debt双方、買戻しはcash/株数双方、増資は調達額/分母双方を動かす。分配停止時のcashを消さず、新規払込を既存株主の価値創出にしない。発行/転換時期と配当権利を起点1株へ換算する。
- 未コミットM&Aを実行済みにせず、織込むなら対価/調達と取得価値を揃える。賃借料とリース負債を二重控除せず、会計変更を成長としない。非現金費用の足戻しは消耗不存在を意味せず、CF反映済みなら重ねない。
- 金融のcash−debtを余剰株主資産とせず、規制資本・普通株主資本・OCI・分配可能性を分ける。

<a id="draft-calculation"></a>
### 計算資料

`investment-judgment calculate`はtyped ratio/Projectionの算術だけで文章や売上からterminalを作らない。

`--cash-share-cb`は額面現金＋転換価値超過分の株式交付CBだけの試算。額面は計上債務の消滅と対応し再控除しない。決済VWAP・配当調整参照終値・評価株価、端株現金をVWAPと置く試算・VWAPと終価を結ぶ固定点を分ける。調整時期/本数/権利は原典確認し、連続近似や整数固定点不存在を実決済へ読み替えない。採否は別判断である。

<a id="valuation-context"></a>
### 原価格の成立条件

Pmaxの読み替えは保存条件下の必要値で、独立signal/市場予想ではない。利益・必要資本・分配が同時成立する経路と照合し、Downside不足を追加gateにしない。価値固定の期間延長で年率損失が縮んでも損失額は減らない。実際の遅延が利益・資金・分配・希薄化を変えるならcountercaseを組み直す。

<a id="permanent-loss-axes"></a>
## 永久損失

資金余力・返済・CF・希薄化・顧客集中・構造的衰退・governance/accountingの7軸を調べる。確認済み曝露を規模/確率未確定のためunknownへ戻さない。verifiedは記した根拠の確認範囲で、安全保証ではない。赤字/下方修正だけで永久損失とせず、引受根拠不足を小口/overrideで通さない。

<a id="uncertainty-and-decision"></a>
## 不確実性を引き受ける判断

`intact`は明示仮説が既知事実で未破綻、`uncertain`は仮説/中核根拠の整理不足で評価未完、`broken`は仮説不成立。将来利益率等の未確定だけでuncertainにせず、別の再建/回収仮説は検討できるが、反証された旧仮説を安さで復活させない。

supportedには未破綻以上の積極的な価値根拠が必要。確認事実と仮定を分け、不明点、利益/資金/希薄化/価値への影響、基準経路を選び見返りで引き受ける理由を所見・計算・最強反証へ結ぶ。[Base/Downsideの方針](../doctrine.md#fact-analysis-separation)に従い、損失を書くだけで受容済みとしない。顧客別採算が非開示でも総額と妥当な仮定で評価できるが、根拠も代替もない借換成功等を高いBase利回りや架空事実で正当化しない。採否不能なら不足を限定して保留する。観測価格・単位・期間を創作しない。supportedは購入採用ではなく、Pmax超過や提案のquote/cash不足でunsupportedへ変えない。[提案条件](trade-proposal.md#条件付き購入)とは分ける。

機械検証は構造・参照・算術・説明欄を確認するだけで、経済的妥当性は作者と独立検証が判断する。旧`nonmaterial_unknown_reason`の受付を、当時の重要リスク受容審査へ読み替えない。

<a id="independent-second-pass"></a>
## 独立検証と保存

作者と別の作業者が原典・上流算式・当期/前期見出し・単位/期間・仮定/最強反証を確認する。resolvedはterminal/cashを独立入力から再計算し、unresolvedは所見・不足・結論を検討する。抽出値/出力のコピー・同じ誤入力の一致・hash一致を独立性/真実性の証明にしない。[資本の橋渡し](#capital-bridge)と過大/過小仮定の両側、相反/比較不能・unknown/partial・受容理由と検証限界を残す。

評価/Reviewはexact coreのpair、Proposalもそのpairへ束縛する。最新を選んで検証し、unsupported/unresolvedを避けて旧supportedへ戻らない。保存読取へ現在cash/価格条件を適用しない。

<a id="assessment-refresh"></a>
## 差分refreshと文章編集

同日pairは再利用できる。翌日以降の当日算術は価値・開示・仮説・株式単位・残期間/今後分配を差分確認し新Reviewへ束縛する。素材priorと最新supersedes先を分け、source/fact日付を保つ。全資料再取得は不要。旧12か月を延長せず、受取済み分配や今売っても得る確定権利を再算入しない。整数月≠厳密残日数であり、現在projection不可でも旧原価格算術は読める。

編集は数値・単位・日付・比較基準・支持/反証・限定をtitle/summaryまで保つ。同文を各欄へ複写せず、材料→仮定→比較理由へ辿れるようにする。新根拠/因果/判断は変更部分と下流を再Reviewする。
