# 判断文書の編集

文章の編集では、確定した数値・日付・単位・比較基準・source・支持と反証・判断の確度を変えない。本文にあった未確認や適用範囲の限定を、title・summary・下流の含意で落とさない。

語順や構成の整理と、新しい根拠・因果・評価の採用を分ける。後者が必要になったら判断内容を確定する工程へ戻り、変更した判断とその下流をreviewする。構造validationの成功を意味保全の代わりにしない。

観測・導出・見積り・判断の定義は[doctrine](../doctrine.md#fact-analysis-separation)、field固有の意味と発行手順は対象reference・skillが所有する。
