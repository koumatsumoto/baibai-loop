# 判断文書の日本語表現

この規約は、判断文書の内容を確定した後に日本語を編集し、意味が変わっていないことを再検証するための共通正本である。観測事実・導出指標・見積り・判断の定義は[`doctrine.md#fact-analysis-separation`](../doctrine.md#fact-analysis-separation)、指標と各fieldの意味はdomainの正本に従う。

1. **標準用語を使い、見出しを自己完結させる。** 読者がrepositoryの内部語や書き手独自の比喩を知らなくても、見出しだけで対象と変化または状態が分かるようにする。定着した専門用語は正確に使い、raw enum、内部code、未定義の造語を人間向け文章へ漏らさない。
2. **一文に一つの判断を書き、範囲を明示する。** 観測、比較、原因、判断、含意を一文へ詰め込まない。文長を機械的に制限するのではなく、独立して真偽や確度を検証できる単位で分け、主語、対象、期間、母集団など主張の範囲を必要な限り明示する。
3. **観測事実・導出指標・見積り・判断・含意・反証材料・反対仮説を分ける。** 観測事実と導出指標を解釈で上書きせず、見積りを事実と呼ばない。判断は根拠から導いた評価、含意はその判断が下流へ及ぼす意味として書く。反証材料は判断を弱める観測またはsource、反対仮説は同じ観測を別の仕組みで説明する判断であり、同じ語へ畳まない。どちらも何をどこまで弱めるかを明示する。
4. **証拠に合う確度・因果・見出しにする。** 直接確認、複数根拠の統合、因果を識別できない推論、未確認を同じ強さで書かない。見出しは本文より強くせず、上流にある推定・代理指標・未確認という限定を要約や下流の含意まで保持する。
5. **数値に時点と比較基準を添える。** 主張に必要な数値だけを使い、単位、観測時点、比較期間、前年比・前月比・水準、名目・実質、金額・数量など、解釈に必要な基準を示す。公表日と実際の観測期間を分け、比較尺度はsourceの定義から確認する。複数のsourceを「これら」とまとめても、それぞれの観測期間・母集団・測定方法の違いを消さない。異なる基準の数値を無説明に並べず、表示尺度を変える場合は元の値との対応を保つ。
6. **編集で判断内容を変えない。** 語順、文の分割、標準用語、見出しは変更できる。数値、日付、単位、比較基準、source、引用関係、確度、支持・反証関係、限定、構造化fieldの値は変えない。新しいsource、因果、対象範囲、評価が必要になったら日本語編集を止め、判断内容を確定する工程へ戻る。

この規約は短文化、平易化、日本語化率の向上を目的にしない。domain固有のfield一覧とmetric定義は各正本を参照し、巨大なglossaryや禁止語一覧は追加しない。
