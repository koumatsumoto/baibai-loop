# 観測と原典の読み方

ここは観測の意味と限界を扱う。層/保存は[architecture](../architecture.md)、候補は[Screening](screening-runtime.md)、判断は[Stock Assessment](stock-assessment.md)、取得/復旧は[OPERATIONS](../../jobs/OPERATIONS.md)へ。算式/fieldは実装を正本とする。

<a id="source-owners"></a>
## 原典・時点・不足

- **原典**: 原公表機関・公式集約先・企業開示・確認済みbroker事実を使い、報道は補助とする。source tierは正確さ/許諾を保証しない。有料媒体を使わず、契約内の個人・非公開利用に限る。原文/転載表を公開Issueへ再配布しない。
- **時計**: 対象日/会計期、公表/訂正、実受領、入力cutoff、評価時刻を分ける。未知日を受領日で埋めず、Web Archiveの原URL/captureも当時公表の証明にしない。保存入力identityをas-of/latest headで代用しない。固定snapshotは未保持vintage/intradayまでの完全PITではない。
- **比較**: 期間・会計scope・通貨/単位・株式basisを揃え、原値・定義・時計・参照を保つ。加工/転載/再受領を独立証拠、有限fixture/coverageを全市場・将来収益の実証にしない。後日訂正と当時既知を分ける。
- **不足**: 未取得・失敗・取得済み空・partial・正常null・比較不能・明示0を分ける。新期/訂正の不足を旧版・別期・別basisで埋めず、影響を依存値へ局所化する。障害を不存在、固定object破損を正常欠測にせず、原額/独立観測を残す。
- **代替**: 継続障害時に期間・定義・値が複数経路で一致した場合だけ、一次未確認を明示して二次配信を採る。単一値・不一致・一時障害で代用せず、AI転記でstoreを埋めない。実装・受領・公開・切替・計算可能は別である。

[経済catalog](../../engine/src/baibai_engine/data_collection/catalog.yaml)は経済の取得範囲で全L1一覧ではない。他sourceの入口は[取得/復旧](../../jobs/OPERATIONS.md#sources)を参照する。

<a id="financial-periods"></a>
## 開示と会計比較

普通株は[J-Quants原本](../../jobs/OPERATIONS.md#jquants-native-operations)の完全code/商品区分で識別し、末尾0/業種名から推定しない。提案分類・保有名は市場全体で定めた同じ適格日の対象銘柄だけを読む。当日不在を旧日で補わず、無関係な他銘柄の行破損とsnapshot全体の無効記録を区別する。calendar元区分もbooleanから復元しない。JPXは選択完了bundleを使い、旧行を混ぜず、消失を取消/不存在、受領完了を同時公表としない。過去の決算予定は会社IRで再確認する。

[開示選択](../../engine/src/baibai_engine/machine_analysis/observations/financials/financial_documents.py)は期/連結区分/基準を先に定め、訂正/競合をfield単位で扱う。番号・投入順・未知時刻で順序を作らず、空欄を撤回、過年度訂正を現在区分変更としない。時刻不明だけで不変観測を捨てず、flag/空一覧/修正再表示「無」だけで比較可否を決めない。未確定basisを旧FYで迂回しない。

適用翌期の年間業績修正は、同じ会計範囲の翌期年間欄で対象を確認する。利益の点予想がなければ旧EPSを最新として復活させず、撤回/ゼロと断定せず未確定と出典を残す。旧年度のみ・翌期半期のみの修正や通常短信の空欄を年間予想の撤回とはしない。

累計・単独四半期・TTM・期末残高を分ける。EPS/平均株数/営業CFの四半期差分や、異分母EPSの加減算、丸め/basis不明EPSからの総額復元はしない。成長のL3表示でも、保存された表示額/丸め由来の精度と比較原本を数値に伴わせ、未記録の精度を補わない。計算は[財務owner](../../engine/src/baibai_engine/machine_analysis/models/company_financials/metrics/)へ。

主`cfo`は採用した報告期間の金額で、最新開示がCFを含まなければ旧通期などを保持する。`cfo_source`の期間・開示・会計範囲で読み、最新開示日、`ocf_ttm`の合成期間、EDINETの別期フローを付け替えない。既存世代の出典や未知日付は補作せず、報告CFを反復可能な普通株主cashと認定しない。

- **財務/成長の違い**: 財務TTMの最新額合成と成長の累計訂正制約は別契約。配当/予想文書で実績を消さず、予想混入/単一四半期の年率化はしない。前年累計の配信がFYより後でも原資料は先行し得る。
- **成長の窓**: 会計期末の表示窓外の比較元/訂正も使い、窓変更で共通期の意味を変えず読取から取得しない。売却/M&A/為替/会計方針を組替済みの有機成長とは呼ばない。組替値の遡及供給は保証されず、重要差はL3が原典で評価し原観測を保つ。
- **利益/倍率**: 報告利益のYは分配可能利益/期待収益率ではない。連結親会社帰属利益・単体純利益は、優先配当等を控除した普通株利益とは限らない。会社の基本EPSは当該期の普通株利益・期中平均株数に対応し、旧保存の `financial.eps` は報告利益を自己株控除後株数で割った別の値。会社予想/consensusとも分け、優先配当等を推定せず、予想利益の大小や赤字注記だけで持続性を決めない。
- **変化**: 赤字縮小/黒字化は額と符号で読み、負/0基準の率で改善を決めない。営業利益の経常利益代用、金融業への非金融利益率適用、未検証basisの変化率を避け、成長系列はPERや同業倍率を評価しない。この二つを全社共通の「未提供」欄としては出さず、過去の保存資料に実際にあった注記だけを表示する。倍率を見るときは同世代の企業財務の期間・利益・株式基準を、比較する場合は明示した相手の資料を読む。新規生成は報告EPS・期中平均株数・発行済株数・自己株数を各期の原単位で残し、株式基準の異同を確かめられないため前年ペアを作らない。株数変動は開示と[資本補正](../../engine/src/baibai_engine/machine_analysis/models/company_financials/metrics/capital.py)で確認する。明示した期間窓の外にある原額は、その会社の元資料または広い範囲の保存モデルで読む。

### 原本内の比較と組替

EDINETは同じmarket sealに適格な任意入力で、未取得でも全社生成/J-Quantsを止めない。CSV/XBRL、原本受領/抽出を分け、[保持/再開](../../jobs/OPERATIONS.md#edinet-list-native-l1)に従う。再抽出で初回bytesを差し替えず、提供元修復後も隔離取得/差分確認を要する。

[comparison再利用](../../engine/src/baibai_engine/machine_analysis/generation/comparison_evidence.py)は任意cache。同じ原本/抽出入力・revisionに一致する適格入力だけ再利用し、旧/不正形式なら再抽出する。原本の取得/保持を代替せず、cold再生成に前回L2を要しない。

EDINETでは明示された日本/米国基準もIFRS抽出の確定的な非対象として再利用するが、空/未知基準・観測全体の欠測/解析失敗は再試行する。成功観測内の個別operand欠測は、その理由を保って再利用できる。旧来の非対応理由から確定非対象を推定しない。現在の文書状態・親と固定type=1受領のhashが一致する確定非対象だけは、金額を用いないためZIPを読み直さない。これは保管物が現在も読めるという検査ではない。金額を取り得るIFRSや未確定・状態変更は固定原本を読み、原本を明示して開く場合や前回観測なしの再生成も実物の欠落・破損を拒否する。

| 経路 | 固有の成立範囲 |
| --- | --- |
| [EDINET同一文書](../../engine/src/baibai_engine/machine_analysis/observations/financials/edinet_comparisons.py) | IFRS年次/半期本表の当期・比較期は企業財務（`financial.reported_comparisons`）に保存する。成長系列の期間窓/不足とは別で、企業成長しか持たない新しい単独出力からは読めない。旧成長に保存された比較は当時のまま読む。J-Quants TTM/倍率へ横結合せず、単体利益を親利益、相対年度名を比較日に読み替えない。 |
| [PDF組替](../../engine/src/baibai_engine/machine_analysis/observations/financials/pdf_selection.py) | 最新期/訂正を照合した同一基準の比較欄/TTM。日本基準の遡及変更は同日公表の組替済み前期実績を要し、表示丸めの近似/不明を精密XBRL値としない。参考実績は年度の訂正原本ではなく、四半期とは別の公表時計で照合する。後の年次訂正や公表順不明を再確認済みとしない。 |

同日IFRS年次operandも、そのPDFに一致するnative文書の時計で四半期以前を確認する。額不変で旧PDFを使う場合は、後のEPS訂正の時刻を借用しない。

IFRSの組替注記と前・当の列役割は実際の測定期へ限定し、通期・Q1・中間期の別期間から借用しない。IFRS中間の明示的な組替比較は累計の同一表として扱い、表紙と本表の対象期・値を照合する。半年の比較値だけで単Q前年比やTTMを埋めず、表示丸めの精度と原受領時刻を保つ。

年度そのものと同期間のTTM比較は、検証済みの同じ年次PDF比較欄へ揃える。旧nativeの前年値へ戻して成長方向を変えず、過去観測は原文書のまま保つ。中間期TTMや後発の額不変訂正へ比較欄の確認を拡張しない。 後発訂正で比較欄が未確認なら、既存の組替比較と明確に矛盾し、それより公表時点も古い前年値から成長を復活させず、その科目の比較を保留する。当期額・無関係な科目・元の過去観測は残す。

後続の中間期PDFが未受領でも、同じ直前年度・連結範囲の明示的な再表示と旧年度operandの既知矛盾を忘れてTTMを復活させない。参考年度だけで新しい中間期比較を補作せず、当期の原観測と元の比較は残す。PDF欠測や変更flagだけでは保留せず、表示丸めの一単位差を確定矛盾にしない。

訂正系列を保ち、組替成功でも未受領訂正や金融業/業種不明の利益率制約を解除しない。[fixture](../../tests/fixtures/edinet/comparisons/README.md)の年次/半期をQ1/Q3・全本表へ、PDF受領をXBRL取得へ一般化しない。

<a id="capital-basis"></a>
### 資本・価格・配当の単位

発行済総数/平均株数、普通株自己資本/非支配持分込み純資産を分ける。自己株控除は同じ資本状態で行い、新しい自己株欠測を旧状態で補って処分/消却を推測しない。 利益利回りの不足理由には利益・価格・会計範囲の不足も含まれ、価格と株数が有効な場合もある。資本だけの不成立と読み替えず、元の理由を保持し、旧保存の呼称も後から書き換えない。

PBRの`book_equity`は実際に選んだ分母・算式・元開示を示す。自己資本比率経路と、as-of株式basisへ換算したBPS×現在株数経路を区別し、別sourceのEDINET連結scopeや最新開示日を簿価へ付け替えない。出典があっても現在の普通株持分・平均資本ROE・換金価値を保証せず、旧世代に出典を補作しない。

EDINETの金融残高は、簿価や予想と別の出典・連結範囲で読む。現預金と現金同等物の選択科目は旧metricで保持されず、年度metadataはBS実測日ではない。金利負債は抽出科目の合計で、注記だけにある内訳の網羅を保証しない。net cashや投資有価証券だけでは全負債・非支配持分・必要資金の控除や換金可能性を確認できず、普通株へ配れる額にしない。持分法投資と持分利益、金融資産とその運用益の重複は[資本bridge](stock-assessment.md#capital-bridge)で判断する。

短信の現金同等物は、採用元の報告期・文書をEDINET残高と分けて読む。最新開示日や複数BS項目の最大carry日数をその出所へ付け替えず、旧世代の未知出典を補作しない。出典があっても現時点の残高・両系列の差の原因・自由に配れるcashを認定しない。

期末株数と遡及分割EPS/BPSの混在は[資本補正](../../engine/src/baibai_engine/machine_analysis/models/company_financials/metrics/capital.py)の裏付けで扱い、数値一致だけで誤転記にしない。連続する分割の一部だけが反映済みの場合も、各per-share値と独立総額で既知の株式basisを照合し、複数basisが成立するfieldは未解決にする。JPX PDFの転換も完了と普通株basisを確認し、新発行済数と旧自己株を混ぜない。 後発事象による後日開示は明示効力日と公表日を分け、公表日前のas-ofへ戻さない。取得済み原本の実受領cutoffも別に保ち、予定・複数完了・不一致は株数の推定に使わない。

大量保有報告の株式総数は第三者の申告で、発行会社の自己株数や変更日を確定しない。通常の企業財務には取り込まない。欄がない新しい世代を「報告なし・希薄化なし」と読まず、古い固定モデルの同欄は当時のpartial等の範囲のまま扱う。必要な個社調査では、受領した一覧で対象文書・訂正/撤回・受領時点を確かめ、[特定した原本の抽出](../../engine/src/baibai_engine/machine_analysis/observations/financials/edinet_holder_capital.py)で発行会社・株式数・基準日を読む。文書の提出時計は受領時計ではなく、その確認だけで過去の可視性や現在の分母を証明しない。

[発行会社の資本注記](../../engine/src/baibai_engine/machine_analysis/observations/financials/edinet_issuer_capital_reader.py)は最新年次/訂正の同じ普通株表の期末表示。提出日contextや議決権表を接合せず、単位・scope・原文位置を保つ。信託/分割注記は未照合で、現在株数/価格分母の補完や、最新訂正の欠測から旧数値の復活に使わない。

[価格換算](../../engine/src/baibai_engine/machine_analysis/observations/prices/price_basis.py)はraw closeを同じ基準へ揃え、別取得世代の調整価格をつながない。rights issueを含む価格調整と、確定分割/併合だけの株数/配当換算を分け、価格から株数を逆算しない。

実績DPSは期/原単位/分割を確認し、不明actionを解決済みにしない。採用元の報告期・文書は予想sourceと分け、欠測期間を最新開示日や予想年度で補わない。四半期末を基準日、総額÷期末株数を換算値とせず、相殺で変更を消さない。無配/未解決を分け、欠年度を飛ばして増配streakを復活させない。予想/原額を保ち、旧carryを実現配当としない。適用年度の配当訂正に年間額がなければ旧予想を復活させず、翌年度slotの訂正は翌年度の支払期情報で対象を確認する。

### EDINET金額を評価へ使うとき

[CSV抽出](../../engine/src/baibai_engine/machine_analysis/observations/financials/edinet_metrics/csv.py)の基準/context・0/空欄・合算/内訳を使い、本表とsegment、JP/IFRSを混ぜず、独自concept/類似名から全額を推定しない。

IFRSの金利負債は、流動・非流動の社債及び借入金とリース負債が標準科目で揃う表示を採用する。借入金だけ、その他金融負債、注記本文から不足分を埋めず、合算額へ借入内訳を重ねない。これは抽出できる残高の範囲であり、全債務や普通株への分配可能資金を保証しない。

日本基準でも、選択した当期scopeに未対応の銀行借用金・短期社債が非0または未解決で存在するときは、対応科目だけの部分和をdebt/net cashへ採用しない。欠測理由に元要素を残す。銀行の預金等を一般事業会社の負債へ加算する規則ではなく、明示0や別期・別scopeまで欠測扱いに広げない。

- **残高**: 現預金と現金同等物を分け、抽出債務を網羅としない。証券は税・拘束・換金性などを引く前の帳簿額、net cashは時点残高。非金融の業種分類でも連結ファンドの外部出資者に帰属し得るため、合算を普通株の資産裏付けとしない。旧保存倍率は当時の単純合算で清算価値ではない。
- **EBITDA**: 同書類の対応償却を使い、異なるCF加算子の省略や、のれん償却による減価償却補完をしない。負EV/負EBITDAを分け、負倍率を割安としない。
- **OCF/capex**: 運転資金内訳は年次、標準科目の有形/無形取得支出は年次と中間の部分内訳で、税・契約債務・必要資金を網羅しない。OCF内訳はCFへの寄与符号、設備支出は正の支出額。欠測を0、合算CapExを推定分解せず、J-Quants OCFと混ぜてFCFを作らない。内訳0の感応度を正常FCF/維持投資とせず、原本取得対象は広げない。中間の部分支出だけで完全FCFや年間利回りを作らない。
- **財務cash支出**: 同じ当期scopeのJP標準科目で確認できるリース返済と非支配株主配当は、元のCF符号の別内訳として残す。年次/中間を年率化せず、欠測・未対応科目を0や別期間で補わない。非支配配当は連結に限り、issuer拡張や未検証のIFRS類似名を推測しない。既存OCF−設備取得支出のFCFから機械的に再控除したり、リース残高・非支配利益をcashと読み替えたりしない。CFO内の支払との重複、維持投資・税・資金拘束等を原典でつなぐ前は普通株主の分配可能額ではない。
- **期間**: annual exactは年度metadataで最新TTM/実測context/持続性の保証でない。半期・変則/不明年度を年率化せず、context日を年度/提出日で補わない。短信OCF TTMとの精度差を保ち、異期間FCF/CFOを差し引かない。

短信との規模照合は範囲ずれ検知で同時点/連結範囲の証明でなく、BS時点/debt scopeも開示日・期末・carry lagから推定しない。

<a id="edinet-research-facts"></a>
Company Research factsは年次/訂正と比較年度の任意入力。外部/内部売上・利益basis・区分変更を揃え、提出JST日以前へ遡及しない。JP GAAPの明示元本は社債括弧額を重複せず、リース/利率/担保/covenant/IFRS/5年超残差を網羅しない。抽出ok/0行を負債0とせず、失敗で既存factを消さず、CF/借換推定を混ぜない。

### 個社・市場・業種の相対比較

各時点以下の最新masterの普通株を使い、除外銘柄を旧snapshotから戻したり母集団を候補へ縮めたりしない。市場breadthはbenchmarkと同じ価格日、個社相対はbenchmark/自己除外peerと両端日を揃える。業種表は採用価格日を保持し、benchmark欠測時は既存の最新価格日fallbackを使う。過去成果に日付がなければ不明のまま読み、as_ofで補わない。業種表の成立はbreadth成功でなく、各社bar窓の中央値も共通開始日を保証しない。補間/業種中央値で端点不足を埋めず、ratio差0.1は10 percentage pointsで割安ではなく、自己価格順位と旧倍率レンジ位置も別である。

業種表の20/60bar騰落とMA20 breadthは必要な履歴が異なるため、各指標の有効母数を併読する。`ticker_count`は従来どおり20bar騰落の母数に限り、長短の中央値を同一社群の変化と認定しない。MC v17以降の`sample_sizes`は初回比較・Researchへ保存するが、旧未記録を0や20bar母数で補わず、旧値も再推計しない。標本数は精度・将来勝率や新しい候補条件ではない。

市場breadthの上昇は、各時点の有効母集団と動く移動平均に対する位置の変化であり、同一企業群の価格上昇率や利益回復率ではない。価格横ばいでも平均線の低下だけで上回り得るため、回復を判断する時は価格変化・比較窓・母集団を分けて確かめる。同一社群の私的対照も当時masterや公表時点の再現とは区別し、旧保存の比率を置き換えない。

不正な価格は依存する比較端点・窓を欠測にし、古い価格日へ繰り上げない。他社や独立した端点比較まで一律に消さない。

`realized_vol_20d`は年率換算するため、個社の実在barを詰めず、共通営業日窓の全終値を要する。calendarや終値が欠ければ数値を出さず、窓・有効終値数・欠測理由を併読する。旧計算revisionの同名fieldは実在20bar間の変化で、連続した日次観測とは限らない。新規Generationを使うResearchの完全モデルには新定義と不足を渡すが、初回候補のcompact表示には追加しない。保存済み数値やSelectionを新方式で置換・後補完せず、候補の順位/採否・売買条件にも使わない。これは配当なし価格変動の記述量で、将来損失・事業リスク・要求収益率そのものではない。

新規の個社市場モデルは、現在の株価を自社の過去750本で順位付けしない。過去の値位置は、事業価値や同業比の安さではない。既に保存された分位は当時の記録として残す。直近最大252本の高安、実際の価格・終端・取引期間、比較可能な同業や市場の値は引き続き個別に読める。

個社の`relative_1d/5d/20d/60d`は実在価格bar間の差で、共通営業日数ではない。欠測・停止を挟むと長期間になり得るため、L3初回比較でも`comparison_windows`の両端日を併読する。benchmarkの端点欠測と個社の窓不足を分け、日付のない旧結果へ現在の窓を補わない。

<a id="market-conditioned-activity"></a>
### 市場方向別の価格と円代金

市場上昇日/下落日の条件付き比較は、期間全体の相対上昇と下落日耐性を分ける観測である。共通営業日の連続した同日returnだけを使い、途中欠測を飛ばして多日変化を一日へ圧縮しない。日経225・TOPIXのETF代理を初回候補比較でも別々に示し、片方の欠測を他方で補完しない。代理ごとに上昇/下落の日集合が異なり得るため、一方の条件付き強さを市場一般へ外挿せず、二つを独立した支持票にも数えない。配当込み指数・beta調整alpha・投資可能な累積収益ではなく、短標本や一日の外れ値で解釈が変わる。売買代金の当日/直前窓比較は当日を基準平均から除き、株数出来高へ換算しない。これらは価格仮説や時期の比較に渡す観測で、順位/採否を変える点数・主体判定・約定容量ではない。旧保存結果への補完は行わない。

市場下落日の平均上昇・超過と、個社上昇日数・市場超過日数は別に読む。初回比較にも保存された日数を残すが、勝率・信頼度や新しい選別条件にはせず、旧未記録は補完しない。

市場方向別の円売買代金は同じ日の値だけを区分し、個社の上昇/下落日や前日の代金と混ぜない。同じ市場下落日群でも、個社上昇と大商いが同時に生じたことまでは集計値から言えない。市場方向の判定と個社価格比較・代金統計の成立は別で、個社終値不足だけで保持代金を消さず、代金不足で価格比較を消さない。条件日数と有効代金数を併読し、条件内の欠測を除いた部分平均・中央値は出さない。条件日なしは平均0でなく不明、観測された代金0とは異なる。これは窓の終端tで読める過去の記述量で、各過去日sに既知だった信号ではない。tの直前窓をsの基準へ流用する正規化や、新しい倍率・売買条件は追加しない。

市場下落日の個社上昇/非上昇別の円代金は、価格方向と同日の商いを対応させる補足である。非上昇には横ばいを含み、市場の上昇/横ばい日はどちらにも入れない。方向の比較に必要な価格が不足すればこの交差は不明だが、市場方向だけの代金観測は独立に残す。個社上昇群の代金が大きくても買い主体・資金流入・将来勝率ではなく、各過去日の平常比が増えた証明でもない。当日の高い倍率を別日の交差へ移さず、旧保存にこの区分を後補完しない。

条件付き60営業日と当日対直前20営業日の代金観測は、同じ固定snapshotから終値・価格調整と独立に読む。終値が全て欠測でも保持代金の観測は残し、価格・相対の区画が代金観測だけを持つ場合がある。それを価格・価格日・returnの存在とせず、旧保存モデルには後補完しない。

<a id="technical-analysis"></a>
### テクニカル分析の窓と経路

[TA](../../engine/src/baibai_engine/machine_analysis/models/technical_analysis/)は配当なしの調整終値を使う。bar本数は窓・鮮度・流動性・取引可能性を保証せず、慣例期間の最適性、BBの95%包含/反転確率、RSIのbuy/sellを仮定しない。SMAの価格差は観測終端の位置であり、線を回復した日時や場中の売却条件ではない。旧保存モデルへ追加期間のSMAを後補完しない。RSIの履歴依存やflat中立値は計算規約である。

12–1モメンタムは直近月相当を除く価格履歴で、評価参照日と騰落の実終端を分ける。終端より後の決算・予想文書への反応とは読まないが、最新の採用文書日を予想の初公表/改訂日や、それ以前は未知だった証明にもしない。同じ予想の再掲はあり得る。

共通calendar端点returnと実在最高終値peakからの下落は別で、未観測日の最高値保証/前年比returnとしない。価格なしでは無約定/終日停止を識別できず、row不在/部分欠測/不正値を分ける。途中が欠けても実在する端点間の騰落は読めるが、観測高値より高い価格が欠測日に存在しなかったとは言えない。

60営業日の経路統計は全日の価格がある場合だけ計算し、端点returnが読めても途中欠測を平滑な上昇としない。新統計は有効終値の存在で計算し、売買代金等の不足を終値欠測に置き換えない。六項目coverageとは判定範囲が異なるため、それぞれのbasisと不足を保持する。方向付きの経路効率は上昇の大きさ・一日の変化への集中・現在高値からの距離・期間内最大下落と併読し、一日の急騰でも高くなることや、過去下落が将来損失上限でないことを保つ。上昇/下落の活動比較は日数を除いた一日平均**売買代金**で、株数出来高・買い越し・機関蓄積ではなく価格変化の影響も受ける。片側の日がない場合や代金不足を比率0で埋めない。

技術の初回比較にもG60の端点return・高値比・最大下落・経路効率・一日集中を、元の窓・価格basis・不足状態とともに渡す。調整済みの分析価格そのものは注文値として併記しない。経済順位・採否を変えるscore/売却ruleではない。SMAの実在bar窓と共通営業日窓は同一とは限らず、それぞれの日付と不足を読む。

押し目は同じ完全な60営業日窓の既観測最高終値を下回る区間として読み、初めて元の高値以上へ戻った時だけ回復とする。現在の未回復区間と直近の回復済み区間を併記し、回復済みの小さな押し目だけを選ばない。底は観測時点までの最低終値で、将来の底・回復日ではない。同値の高値は直近、同値の底は最初の日を採り、窓左端の高値には左側履歴の打切りがあり得る。日数は共通営業日の差で、途中欠測を詰めず、窓外の経路・最高値・全保有期間を保証しない。L3では同じ企業価値仮定の下で今引き受ける経路、回復水準を待つ条件と機会費用を比べる。回復水準は支持抵抗や回復確率の認定ではなく、経路の滑らかさを企業価値へ上乗せしない。旧保存結果には新しい区間を補完しない。

直近の反発と再失速が長い未回復区間へ畳まれるため、R20の共通21終値にも同じ定義の現在/直近回復の最大2区間だけを保持する。20日は既存の比較窓であって推奨待機期限ではない。短期の回復は60日経路の回復を意味せず、両窓と有効性を併読する。R20端点returnが有効でも途中欠測があれば区間は不明で、該当区間なしとは区別する。

売られ過ぎを調べるときは、当該株の騰落・観測高値からの下落率と期間、同じ端点の指数、事業価値の変化を比べる。新規モデルは全社に同じ閾値の「急落」ラベルを付けない。旧注記は保存された当時の研究目安として読める。旧MC窓/高値や旧run母集団を現方式で再計算しない。

<a id="external-assessment"></a>
## 外部評価と記事

モデル価格・予想/rating・Quants score・投稿/総合診断を分け、origin/尺度を揃える。初回/欠測回復/人数変更は改善でなく、保存最新値は現在値/最新試行成功でない。受領間比較を自己評価との比較とせず、人数/年表示/過去列から未記載の期末/EPS/履歴を作らない。銘柄同一性のない404/「情報なし」は正常欠測でない。

latest/previousは隣接した保存受領で、連続した営業日の観測とは限らない。両方の受領時計と、scoreでは両方の基準日を読んで、欠けた過去情報の回復を当日の改訂としない。受領間隔は提供元の改訂時刻を確定しない。

株マップの銘柄同一性と明示的な未計算表示が成立する場合は、提供元日付・scoreのない`not_computed`観測を元の受領時計で保存する。日付のない未知HTMLや数値との矛盾は解析失敗のまま残す。最新の未計算観測を捨てて過去scoreを現在値へ戻さず、日付のある通常欠測とも区別する。

<a id="tradingview"></a>
保存HTML/SDK応答はnative表現でwire bytesではない。取得単位・拒否・再開は[外部評価](../../jobs/OPERATIONS.md#external-assessment-acquisition)・[TradingView](../../jobs/OPERATIONS.md#tradingview-expectations)へ。

TradingViewの受領JST日/master日を公表日、部分公開を市場代表としない。metric別の通貨・FY/next FY・人数を一括流用せず、実受領cutoff/次取引機会を守る。2回の受領値は当時の観測として読み、個々の対象期間が照合できないまま予想の上方/下方修正とはしない。参考closeは株価の第二正本でない。

<a id="public-articles"></a>
索引/本文受領/投影/主張抽出を分け、見出し/概要/全文/部分の範囲を保つ。抽出待ちの理由・抽出状態にも選択入力の本文範囲を残し、概要の再抽出だけで本文不足が解決するとはしない。BBC World/Business・Fed/ECBの通常取得はRSS見出し/概要までで、本文実読とせず、発言を政策決定としない。取得範囲と[exact回復](../../jobs/OPERATIONS.md#article-acquisition)は運用、判断接続の受入は[#1705](https://github.com/koumatsumoto/baibai-loop/issues/1705)へ。金利CSVを独立測定、XLSXセル投影を図表/書式/計算結果の復元にしない。

社会動向の明示baselineとの主張差分は、数値が同じでも主張種別や発生日の変化を含む。発生日の未知から既知への変化も報告内容の差であり、新しい経済変化の発生を確定しない。受領・抽出・公表日時や引用だけの差を内容変更にせず、予定日通過を実施確認にしない。同一event・現在状態の上書き・因果・金融的重要性は、この差分flagから認定しない。

## 判断への受渡し

Research Selectionは決算予定/規制/現在台帳を網羅するとは限らず、表示拡大では保存入力/生成範囲も増えない。固定旧入力から別Generationを保存する専用CLIは未提供で、現在market公開jobを代用しない。

保存前のselection-contextは省略したモデルの完全結果を`generation_model_ref`の固定Generation・subject・model_idで示す。[既存reader](../../engine/src/baibai_engine/machine_analysis/generation/query.py)の`read_model_inputs`へそのGenerationとsubjectを渡して読む。prepare後の`full_result_ref`はOperation内の保存sliceに限られ、未relatedの業種本文は含まない。未relatedの共有材料は[共有subjectの明示読取](../../.agents/skills/investment-judgment/SKILL.md#会社に未関連の共有材料を調べる)で同Generationから探す。保存planの一覧は生成済み本文の保証でなく、旧plan未記録を現在catalogで補わない。読取は元payloadと固定入力identityを返し、会社への関連・観測の実施/現在性・価値採択を認定しない。

[SRC](https://holistic-r.org/report/)・[フィスコ](https://www.fisco.co.jp/service/report/)・[トウシル](https://media.rakuten-sec.net/)などの事業・成長・競争・懸念に関する見解は、重要な仮説の前提・反証を調べる補助に使う。対象と問いに合う保存済み資料・[記事本文](../../.agents/skills/investment-judgment/SKILL.md#記事の原文へ戻る)から始め、不足時に公開原本へ進む。目標株価/ratingだけで済ませず、著者の因果説明を自分の事業理解・価値実現条件と比べ、判断に関係する差や残る問いを既存Research/Assessmentへ残す。

[根拠の確認](stock-assessment.md#観測と根拠)に従い、実績などの事実・会社説明/計画・著者の独自見解を分け、sponsor調査を独立した裏付けに数えない。公表時点・実読ページ/本文範囲と採用HTTPS原本を残し、古い見解は現況を示す一次資料等と照合する。毎社/全媒体の必読・毎回取得/日次crawlerは要求しない。届かなければ一次資料へ戻る。

保有quoteはJ-Quantsを使い、公開quoteの台帳転記で補わない。補助値には時点/basisを示す。Outcomeは[Ledger](../../.agents/skills/ledger-record/SKILL.md#historical-outcome)、世界経済の解釈/発行履歴は[市場判断skill](../../.agents/skills/market-context-assessment/SKILL.md)へ。
