# Baibai Loop logo

`logo.svg` is the artwork master for the Honey palette (`#F0872E` and `#F3B845`). These colors are for the logo only, not controls or market indicators.

The public assets are rendered from the same mark: transparent header and 16/32 px favicon, opaque 180 px Apple Touch and 192/512 px standard PWA icons. The Android maskable PWA icon is a separate opaque 512 px asset. Keep both waves within the central circle whose radius is 40% of the icon width. With the current layout, even the antialiased edges fit within 38%. The opaque icons use a warm ivory background (`#FFF8E8`).
