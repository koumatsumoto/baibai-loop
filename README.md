# Baibai Loop

一人で日本株の割安さと企業価値の変化を評価する意思決定基盤です。Valuation（独自価値評価）、Market Context（市場環境）、External Assessment（外部参考評価）の三分析領域で整理を進めています。機械処理が観測と候補集合を作り、AIが調査・判断を提案し、人間が最終裁定とbroker操作を行います。ValuationとMarket Contextの計算・保存済み読取を整理し、External Assessmentと調査進行の統合は継続中です。現行配置と未移行範囲は[architecture](./docs/architecture.md#repository-map)を参照します。

初めて読むときも、調査・運用・開発の入口を探すときも、[docs portal](./docs/README.md)から始めます。
