# Baibai Loop

一人で日本株の割安さと企業価値の変化を評価する意思決定基盤です。機械処理が観測と候補集合を作り、AIが調査・判断を提案し、人間が最終裁定とbroker操作を行います。

調査・運用・文書検索は[目的別の入口](./docs/README.md#目的別の入口)、開発・AI作業は[AGENTS](./AGENTS.md)から始めます。

保存済み情報の表示は[Web UI](./web/README.md)、Chatからの読み取りは[Owner MCP](./tools/owner_mcp/README.md)を使います。投資方針は[doctrine](./docs/doctrine.md)、構成は[architecture](./docs/architecture.md)を参照してください。
