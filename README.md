# Baibai Loop

一人で日本株の割安さと企業価値の変化を評価する意思決定基盤です。Valuation（独自価値評価）、Market Context（市場環境）、External Assessment（外部参考評価）の三分析領域を使います。機械処理が観測と候補集合を作り、AIが明示開始の有限調査から判断・提案を作り、人間が最終裁定とbroker操作を行います。

調査・運用・開発の入口は[docs portal](./docs/README.md)、現行配置と責務は[architecture](./docs/architecture.md#repository-map)を参照します。本番移行と運用受入の進捗は[Issue #1414](https://github.com/koumatsumoto/baibai-loop/issues/1414)で確認します。
