# Baibai Loop

一人で日本株の割安さと企業価値の変化を評価する意思決定基盤です。L1 Collection（外部原本）、L2（機械的な分析）、L3（統合・解釈・判断）を主軸とし、Valuation・Market Context・External Assessment・Technical Analysisは主にL2の分析結果を整理する区分です。機械処理が観測と候補集合を作り、AIが明示開始の有限調査から判断・提案を作り、人間が最終裁定とbroker操作を行います。

調査・運用・開発の入口は[docs portal](./docs/README.md)、現行配置と責務は[architecture](./docs/architecture.md#repository-map)を参照します。完了した情報層の本番切替と受入記録は[Issue #1543](https://github.com/koumatsumoto/baibai-loop/issues/1543)で確認します。
