# Baibai Loop

日本個別株の割安な機会を探し、企業価値と条件付きの見返りを調べ、根拠付きの売買提案へつなげるシステムです。最終裁定とbroker操作は人間が行います。

**まず[アーキテクチャ](docs/architecture.md)を読んでください。** 原本の受領、機械分析、判断の責務と依存を理解すると、フォルダ名から調べる場所・変更する場所を辿れます。

投資と開発の判断基準は[doctrine](docs/doctrine.md)、環境準備と検証は[development](docs/development.md)にあります。実操作は[Research](.agents/skills/research/SKILL.md)、[取引事実の記録](.agents/skills/ledger-record/SKILL.md)、[市場判断](.agents/skills/market-context-assessment/SKILL.md)、[運用手順](batch/OPERATIONS.md)から進めます。
