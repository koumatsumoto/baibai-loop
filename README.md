# Baibai Loop

日本個別株の割安な機会を探し、観測と企業・市場情報から価値・価格・リスクを比べ、根拠付きの売買提案を作ります。最終採否とbroker操作は人間が行います。

**まず[アーキテクチャ](docs/architecture.md)へ。** 情報と判断の流れ・責務・保存の正本から、読む場所と変更先を選べます。

判断基準は[doctrine](docs/doctrine.md)、環境準備・検証は[development](docs/development.md)。実操作は[企業判断](.agents/skills/investment-judgment/SKILL.md)・[取引事実の記録](.agents/skills/ledger-record/SKILL.md)・[市場判断](.agents/skills/market-context-assessment/SKILL.md)・[取得/公開/復旧](jobs/OPERATIONS.md)へ進みます。

コードと文書の変更は[AGENTS](AGENTS.md)に従います。
