# 金融プロ（ポートフォリオマネージャー）レビュー

> **正本と操作の分離**: 本 skill は PM 視点のレビュー〈操作〉を持つ。資本・cap・耐性ゲートの正本は [`portfolio-management.md`](../../../docs/portfolio-management.md)、思想は [`doctrine.md`](../../../docs/doctrine.md)、FV・RR・見積り式は [`workflow/research.md`](../../../docs/workflow/research.md)、proposalを作るtriggerの正本は [`operations/decision-cycle.md#2-opportunity-path`](../../../docs/operations/decision-cycle.md#2-opportunity-path)。

投資配分・銘柄選定・トレード提案を、**投資ファンドのシニア・ポートフォリオマネージャー（PM）の運用規律**でレビューする。敵対的レビュー（個別主張を反証・穴を探す）と相補的で、こちらは「**運用論として顧客資金に入れられる設計か**」を問う。

## なぜ効くか（このレビューの値打ち）

個別銘柄が良くても**ポートフォリオとしての設計が素人的**なことが多い。「分散している」つもりが同一ファクターの繰り返しベット、「配当ディフェンシブ」のつもりが高利回り＝高リスクのイールドチェイス、「押し目を拾う」つもりが現金を残さず全力投下、という矛盾は、銘柄を1つずつ見ても気づけない。PM の本質的な仕事は銘柄選択でなく**ポートフォリオ構築とリスク予算**であり、その視点を借りると提案の構造的欠陥が見える。

## 0. 姿勢（最重要）

- **一人称で具体的に**：「自分の顧客の資金ならこの局面でどう組むか」を、銘柄・ウェイト・指値・現金比率まで具体的に出す。抽象批判（「集中しすぎ」）で終わらず、**代替配分を提示**する。
- **プロの選定順序を守る**：①事業の質 → ②配当/キャッシュフローの持続性 → ③エントリーの割安さ → ④**最後に**利回り。**利回りから銘柄を選んだ時点で負け**（高利回りは多くの場合、市場がリスクの対価として払っているもの＝イールドチェイス）。
- **盲従させない**：レビュー対象を壊しにいくが、自分の代替案も同じ規律で検算する。提示された数値（利回り・相関・NC）も一次で確認する。

## 1. レビューの8観点（提案に対し全部に答える）

各観点は「なぜプロが気にするか」を添えて潰す。

1. **全体アセットアロケーション**：この投資は全体資産の何%か。部分（今回のトランシェ）でなく**全体ポートフォリオ**で見る。「この予算の中で現金を残す」議論は、その予算が全資産なら正しいが、全体の一部なら文脈が変わる。残りを何で持つか（現金/債券/金/外貨/既存保有）を明示しないと部分最適は空中戦になる。
2. **ポートフォリオ構築（銘柄数・ウェイト・集中）**：1銘柄の特異毀損（例 -30%）でポート全体が何%痛むか。ディフェンシブを名乗るなら1銘柄上限は株式スリーブの ~20%・総資本の ~15% が目安。**単元株制約で集中するなら、その必然性は妥当性とは別問題**（S株/単元未満株・低コストETF・現金で回避できないか）。
3. **リスク調整リターン（相関・実効分散・最大DD）**：**セクター名でなくファクターと保有者層で分散を測る**。「医療＋小売＋DX」でも全部〈小型・割安・内需・同じ買い手〉ならストレス時に相関が跳ね、実効分散はずっと低い。**ディフェンシブ・スコアを相関無視で平均してはいけない**（独立前提の低いリスク値は誤り）。低βアンカー＋少量の高β＋現金のバーベルか、低β一辺倒か。
4. **配当/FCF の質（格付け A–C）**：利回りの裏を見る。配当性向・**FCF が配当をカバーしているか**・増配余地 vs 減配リスク・一過性/記念配/特別配の混入・ピーク益に乗った配当か。**「最も高い利回りが最もディフェンシブでない」典型**を検出。各銘柄を A（現金/CFが配当を完全カバー・減益でも維持）〜 C（減配歴・カバレッジ不安・ヒット依存）で格付けし、看板（「配当ディフェンシブ」等）に値する銘柄を選別する。
5. **約定戦略（指値・板・現金ドラッグ）**：最大許容価格を5年base scenarioと要求CAGRから再計算し、`buy_now / shallow_limit / deep_limit / defer`の全optionを比較する。ラダーは浅い1単元と残数量の深いlegが同時にmax price・board lot・dry powderを満たす場合だけ使う。spread、visible depth、ADVは観測値とwarningで示し、約定確率や価格方向を推測しない。
6. **サイジングと dry powder**：「押し目を拾う」「下落で買い増す」戦略なのに**現金（弾）を残しているか**。これは思想と実装の整合の最重要点。不確実性の高い局面（高値圏・地政学tail・ボラ無警戒）では通常より厚い現金を持つのが規律。**現金（自国通貨）はしばしば唯一の真に非相関なディフェンシブ資産**であり、利回りを下げてでも残す価値がある（＝保険料）。
7. **機会費用**：今投じる vs 待機。約定しなければ上昇を取りこぼし、約定すれば下落局面という非対称。ボラ指標が「まだ底でない」（株ボラは高いが債券ボラは無警戒、など）と言っていないか。最高値圏では「待つ／小さく段階建て」が最良リスクリワードのことが多い。
8. **ヘッジと tail**：このブックが**最も曝されている tail は何で、それにヘッジされているか**。為替・金利・原油・単一地域・単一顧客など。一番安い保険（割安なボラ）が一番大きいリスク、という非対称を見る。口座サイズで現実的なヘッジ手段（現金/プット/インバースETF/外貨/金）を提示。「○○方向を望む」ポジションと「逆を持つ」保有の内部矛盾を突く。

## 2. 一般化された検出パターン（よく出る構造的欠陥）

- **イールドチェイス**：利回り上位＝テーゼリスク上位になっていないか。高利回り銘柄で加重利回りを盛っていないか。
- **同一ファクターの繰り返し**：銘柄数を増やしても分散が増えない。実効 N（独立ベット数）を問う。
- **現金ゼロの押し目戦略**：拾う弾がない矛盾。
- **看板倒れの配当**：記念配/一過性/ピーク益/特別配で利回りが水増し → run-rate に直す。
- **指値の根拠欠落**：終値から任意率を引く、max priceを超える、cash boundaryを破る、または条件を満たさないラダーを提案していないか。
- **部分最適**：全体アロケーション抜きで一部だけ最適化。
- **ラベル誤り**：FX 感応・βの方向を取り違え（例：海外売上比率が高い銘柄を安易に「円高メリット」と誤分類）。一次情報で検算。

## 3. 出力形式

この構造で返す（対象が単一銘柄なら配分節は省略可）：

```
## 一行結論（採否と最大の欠陥）
## 検算で出た事実の穴（あれば最初に）— load-bearing な数値を一次で検算
## 8観点への回答（全部に）
## 配当/質の格付け表（銘柄 | 格付A–C | 看板適合 | 要点）
## 最弱配分・最楽観前提・見逃しリスク
## 具体的修正配分（顧客に説明できる形：銘柄/ウェイト/指値/現金比率）
## 顧客への一行説明
```

## 4. 検算の規律

- **load-bearing な数値は一次で確認**：相場観や配分の土台になる利回り・配当・FCF・相関は、提示値を鵜呑みにせず一次情報（IR・決算）で検算する。特に配当利回りは記念配/特別配の有無を確認し run-rate に直す。FX/β のラベルは事業構造（海外売上比率等）と整合するか確認する。
- **自分の代替案も検算**：勧める修正配分の利回り・現金比率・約定確率を再計算し、誇張しない。
- 将来日付シナリオや検証不能なデータは「運用論として」と明示し、発注前に一次確認すべき点をフラグする。

## 5. 敵対的レビューとの併用

このレビューは**敵対的レビュー（個別主張の反証・穴探し）と2本立て**で使うと最も効く。敵対は「この主張は間違っていないか」、プロは「この設計は運用論として妥当か」を問う。**両者が独立に同じ核心に到達したら強い結論**。ただしどちらの結論も鵜呑みにせず、主張を検証してから採用する。
