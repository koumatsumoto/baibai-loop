# 廃止銘柄の除外を有界バイアスとして扱う判定 — 事前登録

## 0. 事前登録（拡張 grid の評価を実行する前に commit する）

現行契約は `unpriced_exit_count` が 1 件でもあれば cohort を production evidence から外す。これを次の判定へ置き換えることを、**拡張 grid の eligibility を評価する前に**ここで固定する。

### 判定規則

cohort の metric について、exit value を持たない銘柄へ次の 2 通りを代入して metric を再計算する。

| 代入 | 値 | 意味 |
| --- | --- | --- |
| 全損 | `price_return = -1.0` | その銘柄が無価値になったとみなす下限 |
| 中立 | 同 cohort の resolved 銘柄の中央値 | 廃止が結果に情報を持たないとみなす基準 |

**cohort が報告した値と両方の代入とで結論の向きが一致するときだけ eligible とする。** 向きが割れる cohort は `unpriced_exit` blocker を維持する。

「結論の向き」は metric ごとに次で定める。

| metric | 向き |
| --- | --- |
| `recommended_rank_top5` / `recommended_rank_top10` | その group の `median_excess` の符号 |
| `er_calibration` | 最上位 quintile の `median_realized_price_excess` − 最下位 quintile の同値の符号（予測の高い側が実現でも高いか） |

`er_calibration` の向きは当初 rank IC と書いたが、実装が返すのは quintile 表で IC ではない。**計測を実行する前に**、実装が実際に持つ量へ定義を揃えた（この訂正自体も計測前の commit として git history に残る）。

### 計測後の改定（開示）

最初に登録した規則は「両方の代入で向きが一致するとき」だけを条件にしていた。これは比較集合に **cohort が報告する値そのもの**（廃止銘柄を落として survivor だけで計算した値）を含まないので、規則が答えるべき問い — その報告値を除外が作ったか — に答えていなかった。§2 の計測を実行したあとにこの穴を見つけ、報告値を比較集合へ加える形へ改定した。

改定は**厳格化の一方向**である。旧規則で eligible だった cohort が新規則で eligible になることはない。**改定前後で eligible な cohort 集合は変わらず**（3y 5 件 / 5y 4 件・`eligible_metric_cohort_count = 9`）、新たに 2 件が block された。結果を見て通したい cohort を通す方向へ規則を動かしていないことは、この不変性で確認できる。

改定後に割れた 2 件は次で、いずれも「報告値と両代入の向きが違う」型である。

| asof | horizon | metric | 報告値 | 全損 | 中立 |
| --- | --- | --- | ---: | ---: | ---: |
| 2020-02-28 | 3y | `recommended_rank_top5` | +0.000000 | +0.021155 | +0.021155 |
| 2020-02-28 | 3y | `recommended_rank_top10` | −0.019074 | +0.002081 | +0.002081 |
| 2021-06-30 | 5y | `recommended_rank_top5` | +0.696842 | −0.208266 | +0.000000 |

2021-06-30 は推奨上位 5 銘柄のうち 2 銘柄が市場から消えており、報告している +0.70 は残る 3 銘柄だけで測った値である。全損を代入すると −0.21 になる。旧規則はこれを「安定」と判定していた。

### 採否基準

- 両側代入の実装が、代入前後で resolved 銘柄の値を変えないこと（代入は unresolved 行にだけ効く）。
- 拡張 grid の 3y / 5y 満期済み cohort について、両側代入の結果と向きの一致・不一致を全件表に出すこと。
- 向きが割れた cohort を eligible にしないこと。

### この判定を採る理由

除外率に閾値（例「5% 未満なら許す」）を置く形も考えたが採らない。閾値は恣意的で、除外が結論を反転させ得るかどうかを直接には答えない。両側代入は「除外された銘柄がどんな値であっても結論は変わらない」を cohort ごとに示すので、答えるべき問いに直接答える。

### 誠実性の限定（先に開示する）

- **盲検ではない。** `reports/2026-07-30-calibration-evidence-eligibility.md` §5.1 で、断面 master 適用後の 2022-09-30 cohort に `unpriced_exit` が 239 件 / 3,771 出ることを既に公表している。規則の設計者はこの水準を知った状態で規則を書いた。
- **上側の bracket は保守的でない。** TOB / MBO による廃止はプレミアム付きで、実現リターンは中立代入より上に出る。2 通りの代入はその場合の真値を挟まない。したがってこの判定は「除外が結論を**下**へ引く可能性」に対しては bracket になるが、上へ引く可能性に対しては中立代入が下限になるだけである。廃止の内訳（上場廃止 / 買収 / 経営統合）を件数で出し、買収由来が多い cohort ではこの限定を明記する。
- **この判定は exit value を作らない。** 廃止時の実際の対価を外部 source から取る道（#420）は依然として別に存在し、両側代入はそれが無い状態で結論の頑健性だけを述べる。

## 1. 対象

拡張 grid（2019-11-29〜2026-06-30 の 80 cohort）の 3y / 5y 満期済み cohort。

## 2. 計測

数値は改定後の規則によるもの。比率は cohort ごとの `liquid_population_count` に対する除外銘柄数である。

| horizon | 満期済み cohort | 廃止を含む cohort | 除外銘柄数（最小 / 中央 / 最大） | 流動性母集団比 | **向きが割れた cohort** |
| --- | ---: | ---: | ---: | ---: | ---: |
| 3y | 44 | 44 | 46 / 58 / 107 | 3.8〜7.2% | **1**（2020-02-28） |
| 5y | 20 | 20 | 84 / 105 / 134 | 7.7〜9.6% | **1**（2021-06-30） |

満期済み cohort は例外なく廃止銘柄を含む。割れた 2 件はいずれも「両方の代入は同じ向きだが、cohort が報告している値だけが逆を向く」型で、旧規則では検出できなかった（§0 の改定を参照）。

## 3. 判定

**規則を採用する。** 事前登録した採否基準を満たす。

- 代入は unresolved 行にだけ効き、resolved 銘柄の値は変えない（実装と unit test で固定）。
- 満期済み 64 cohort の全件で両側代入を計算し、報告値との向きの一致・不一致を出した。
- 向きが割れた 2 件は eligible にしていない。

### 実測から分かった規則の性質（限定）

**この規則が塞ぐのは、廃止が推奨群に集中した場合である。** 推奨上位の指標は中央値なので少数の外れ値に頑健で、向きを動かすには推奨群の相当数が同時に廃止する必要がある。実測で割れた 2 件はまさにその形（2021-06-30 は推奨 5 銘柄中 2 銘柄が廃止）で、残る 62 件が割れなかったのは除外が結論を作らなかったことの証拠であると同時に、この規則が緩い制約であることの証拠でもある。

**上側の限定は事前登録のとおり残る。** 買収による廃止はプレミアム付きで中立代入の上に出るため、両側代入は結論を下へ引く可能性だけを挟む。廃止の内訳（上場廃止 / 買収 / 経営統合）は現在の store から機械的に分けられないので、この限定は解消していない。

**この規則は exit value を作らない。** 廃止時の実際の対価を外部 source から取る道は依然として別に存在し、両側代入はそれが無い状態で結論の頑健性だけを述べる。
