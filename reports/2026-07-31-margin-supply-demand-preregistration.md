# 信用需給 4 軸の採否基準 — 事前登録

## 0. 事前登録（計測を実行する前に commit する）

信用取引週末残高から 4 軸を作った。この軸を rules（gate / ranking / E[r]）へ入れてよいかの基準を、**panel 計測を実行する前に**ここで固定する。

### 対象の軸と仮説方向

方向は実装の `AXES` に既に宣言してある（`direction=-1` = 低いほど良い）。ここでは何を測るかを言葉で固定する。

| 軸 | 定義 | 仮説 |
| --- | --- | --- |
| `margin_long_to_adv` | 信用買い残 ÷ 20 日平均出来高（株数） | 買い残が出来高の何日分も積み上がった銘柄は、戻り売り圧力が将来リターンを削る |
| `margin_long_share` | 買い残 ÷（買い残 + 売り残）、貸借銘柄のみ | 買い方に偏った銘柄は混雑しており、劣後する |
| `margin_long_delta_26w` | 半年の買い残変化 ÷ 発行済株式数 | 買い残が減った後の銘柄は、投げが済んでいる分だけ有利 |
| `margin_std_long_share` | 制度買い残 ÷ 信用買い残 | 6 か月の期日を持つ overhang が多いほど劣後する |

### 採否基準

**軸を rules へ入れる条件は、次の 3 つを同時に満たすことである。**

1. **符号の一貫性**: 1y と 3y の両方で、decile spread（最良 decile と最悪 decile の median excess の差）が仮説方向と同符号であること。
2. **時間 2 分割での再現**: cohort を前半・後半へ 2 分割し、両方で 1. の符号が一致すること。片方だけで出る効果は採らない。
3. **効果量**: 1y の decile spread が絶対値で 3pt 以上であること。統計的有意性は判定に使わない（月次 cohort は forward 窓が重なり独立でないため）。

**満たさない軸は rules へ入れない。** その場合も report は残し、flag は「閾値で立てる warning」ではなく「文脈として表示する数値」へ格下げする。

### 交互作用の検定（トラップ仮説の直接検定）

軸単体の効果とは別に、本 issue の主目的である「割安に見えて混雑している銘柄」を直接検定する。

E[r] 上位 decile の中を `margin_long_to_adv` の上位・下位で 2 分し、両群の forward median excess を比較する。**上位（混雑側）が下位に劣後すれば、混雑バリュートラップは実在する。** この検定は軸を rules へ入れる条件とは独立で、成立すれば OP3 の narrative へ「割安だが混雑している」という文脈を出す根拠になる。

### 先に開示する限定

- **盲検ではない。** 実装中に 2026-07-24 断面の分布（`margin_long_to_adv` 中央値 1.43 日分・p90 15.8 日分）を見ている。ただし forward return との関係は一切見ていない。
- **外部の学術結論を輸入しない。** 週次信用残の予測力を示す研究と、長期では informed でないとする研究の双方が存在する。どちらも採否の根拠にせず、自 panel・自 horizon の計測だけで判定する。
- **3y は cohort 数が少ない。** 10 年の履歴でも 3y 満期済み cohort は 44 件で、forward 窓が重なるため独立標本ではない。cohort 数を標本数として読まない。
- **`margin_long_share` の母集団は貸借銘柄に限られる。** 信用銘柄（実データで 1,558/4,256）は貸株が無く空売り残が構造的にゼロなので、この軸の cross-section には現れない。他の 3 軸とは母集団が違う。
- **分割を跨いだ窓の軸は None になる。** 26 週窓に分割を含む銘柄は実 store で 148（3.3%）。これらはその軸の母集団から落ちる。

### この基準を採る理由

閾値を「IC が有意」に置く形も考えたが採らない。月次 cohort は forward 窓が重なり独立でないので、p 値は標本数を過大に見積もる。decile spread の符号一貫性と時間 2 分割は、独立性を仮定せずに「別々の期間で同じ向きに出るか」を直接問う。

## 1. 対象

拡張 grid（2019-11-29〜、80 cohort）の 1y / 3y。週次残高は 10 年分を backfill し、各 cohort の asof で公表済みの最新残高日を join する。

## 2. 計測

10 年分の週末残高（507 balance date・2,064,052 行、要求 520 週のうち 13 週は取引所が公表せず 0 行として記録）を取り込み、80 cohort の panel を再構築して評価した。

decile spread は「良い側 decile の median excess − 悪い側の同値」で、良い側は宣言した direction で決まる。仮説どおりなら **正**になる。

| 軸 | horizon | cohort | spread 中央値 | 勝率 | 前半 / 後半 |
| --- | --- | ---: | ---: | ---: | --- |
| `margin_long_to_adv` | 1y | 68 | **+0.0978** | 0.74 | +0.086 / +0.102 一致 |
| | 3y | 44 | **+0.3093** | 0.98 | +0.306 / +0.353 一致 |
| `margin_long_share` | 1y | 68 | −0.0559 | 0.15 | −0.056 / −0.058 一致 |
| | 3y | 44 | −0.1271 | 0.02 | −0.131 / −0.125 一致 |
| `margin_long_delta_26w` | 1y | 68 | −0.0102 | 0.43 | −0.024 / +0.005 **割れ** |
| | 3y | 44 | +0.0073 | 0.50 | −0.002 / +0.091 **割れ** |
| `margin_std_long_share` | 1y | 68 | **+0.0450** | 0.76 | +0.033 / +0.050 一致 |
| | 3y | 44 | **+0.1386** | 0.91 | +0.117 / +0.198 一致 |

### 流動性交絡の検定（事前登録に無い追加検定）

`margin_long_to_adv` は分母が出来高なので、流動性の代理変数になっている恐れがある。実際、流動性（`avg_turnover_oku`）との順位相関は **ρ = −0.428**（80 cohort 中央値）で無視できない。そこで各 cohort を流動性 quintile へ層別し、**同じ流動性帯の中で**軸の上下半分を比較した。

| horizon | 層別なし | 流動性 quintile 内 |
| --- | ---: | ---: |
| 1y | +0.0327（勝率 0.74） | **+0.0449（勝率 0.72）** |
| 3y | +0.1742（勝率 0.93） | **+0.1793（勝率 0.93）** |

**効果は層別後も縮まない。** 流動性の代理ではなく、同じ流動性帯の中で建玉の厚みが効いている。`margin_std_long_share` の流動性相関は ρ = +0.146 で交絡は小さい。

### 混雑バリュートラップの交互作用

E[r] 上位 decile を `margin_long_to_adv` で 2 分し、混雑側 − 非混雑側の median excess を出した。

| horizon | cohort | 差の中央値 | 混雑側が劣後した cohort の割合 |
| --- | ---: | ---: | ---: |
| 1y | 68 | −0.0078 | 0.53 |
| 3y | 44 | −0.0328 | 0.64 |

## 3. 判定

事前登録した 3 条件（1y/3y の符号一致・時間 2 分割での再現・1y で 3pt 以上）に照らす。

| 軸 | 判定 |
| --- | --- |
| `margin_long_to_adv` | **採用**。3 条件すべてを満たし、流動性層別後も効果が残る |
| `margin_std_long_share` | **採用**。3 条件すべてを満たす |
| `margin_long_delta_26w` | **不採用**。時間 2 分割で符号が割れ、効果量も 1pt 未満 |
| `margin_long_share` | **不採用**（下記の限定つき） |

### `margin_long_share` — 仮説と逆向きに強く出た

事前登録した仮説は「買い方に偏った銘柄は混雑しており劣後する」（`direction=-1`）。実測は 1y/3y とも**一貫して逆**で、勝率 0.15 / 0.02 は「効果が無い」ではなく「逆向きに強い」ことを示す。

この軸は貸借銘柄に限られ、買い残比率が低い＝空売り残が相対的に厚い状態を意味する。空売り残の厚い銘柄が劣後するのは空売り情報仮説と整合し、実測はその向きに一致している。

**それでも本 report では採用しない。** 計測結果を見てから符号を反転させるのは、事前登録が防ぐために存在する行為そのものである。この効果を使うなら、「空売り残の厚さが劣後を予測する」という**別の仮説として新たに事前登録し、独立に検定する**。ここで記録するのは「仮説は棄却された」ことと「逆向きの一貫した効果が観測された」ことの 2 つで、後者は次の事前登録の動機であって根拠ではない。

### 交互作用は 3y で弱く見える

混雑側の劣後は 3y で −3.3pt・64% の cohort に現れるが、1y は −0.8pt・53% とほぼコイン投げである。**「割安かつ混雑」を単独の警告として立てるには弱い。** flag は閾値で立てる warning ではなく、OP3 の narrative へ渡す文脈値として出す。

### この結果が意味しないこと

- **採用 = rules を変えた、ではない。** 採用は「rules への参入を事前登録つきの別 issue で提案してよい」段階に達したという意味である。gate / ranking / E[r] の変更は本 report では行わない。
- **3y の 44 cohort は独立標本ではない。** forward 窓が重なる月次 cohort なので、勝率 0.98 を「98% の確率で正しい」と読まない。
- **10 年は 1 つの市況しか含まない可能性がある。** 2019-11 以降の cohort は大部分が金融緩和局面で、引き締め局面での挙動は測れていない。
