# 買収型 exit の再投資規約 — 事前登録

価値tier: T2 — 買収で満期前に消える窓を実値化できれば `unresolved_stale_exit` の残り 2 万行超が測定へ戻るが、規約を決めずに素朴に混ぜると短期を過大・長期を過小に測る。規約を先に固定して初めて実値化が correctness 変更になる。

## 1. 固定する問いと非盲検性

破綻型の退出は最終終値で実値化した（`resolved_failure_exit`、[`estimate-calibration.md`](../../../docs/reference/estimate-calibration.md) が正本）。資金が消える退出には再投資の問いが立たないからである。残るのは買収型で、こちらは**現金が戻ってくる**。1 年で +30% の対価を受け取って終わった窓を、5 年複利で生き残った窓と同じ列に並べるのは同じ土俵ではない。

**本書の著者は盲検ではない。** issue #909 の集計で、落ちている行を最終市場終値から組み直した平均が 3m −2.55% / 1y +19.80% / 3y +34.23% / 5y +40.27% であり、`resolved` 群（3m +2.78% / 1y +13.84% / 3y +36.64% / 5y +64.90%）に対し**水平線で符号が反転する**ことを既に見ている。理由別内訳（買収 5,171 行・中央 +28.5%、株式併合のみ 3,569 行・中央 +39.3%）も見ている。これらは「素朴に混ぜてはいけない」という設計上の帰結を示す材料として使い、**どの規約を採るかの根拠には使わない**。

本書を commit するまで、3 規約それぞれの下での cohort 別 return 分布、IC、trap 率、E[r] 較正水準を計測しない。対象行数・ticker 数・退出日の分布・`tender_offer_exit_values` の被覆率は outcome-free source coverage として確認してよい。

この変更が答える問いは「保有期間が途中で消えた窓を、満期まで保有した窓と同じ量として並べる規約は何か」である。買収の予測力、買収されやすさを狙う戦略の収益性は評価しない。

## 2. 対象と非対象

対象は、`jpx_delistings.reason` が買収を示す語（完全子会社化・買収・公開買付・株式等売渡請求・合併・ＭＢＯ・株式移転・株式交換）を含むか、`株式の併合` 単独である退出のうち、現行 status が `unresolved_missing_exit` / `unresolved_stale_exit` の forward 行。

非対象は破綻型（`resolved_failure_exit` で実値化済み）、`unresolved_future_horizon`（水平線が未来にあるだけで欠陥ではない）、上場廃止後の私的整理・再上場の追跡。

## 3. 比較する 3 規約

対価 `C` を退出日 `d`、entry を `e`、entry close を `P_e`、水平線の満期を `T` とする。

| 規約 | 定義 | 含意 |
| --- | --- | --- |
| **A. 現金保持** | `return = C / P_e - 1`。`d` から `T` までは 0% で置く | 退出後に現金が遊ぶ。長期水平線を機械的に過小評価する |
| **B. 母集団再投資** | `d` の時点で同 cohort の生存銘柄等加重指数へ入れ替え、`T` まで持つ | 単一プール運用の実態に最も近い。指数の定義が新たな自由度になる |
| **C. 期間打ち切り年率化** | 保有期間 `(d - e)` の実現 return を年率化し、水平線ではなく**保有年数**で正規化する | 保有期間の違いを吸収するが、複利の再投資リスクを消す |

対価 `C` は `tender_offer_exit_values` にある場合はその 1 株買付価格、無い場合は退出前最終終値とし、どちらを使ったかを行に記録する。

## 4. 採否の基準（結果を見る前に固定する）

**規約は運用実態との対応で選ぶ。結果の良し悪しでは選ばない。**

この system は単一プール ¥10M を月次で配分し、exit で戻った現金は次の選定で再投入される。したがって **B（母集団再投資）を第一候補とする**。A は運用が現金を遊ばせないので実態と違い、C は「保有年数」を水平線と読み替えるので、水平線ごとに較正している現行契約と単位が合わない。

3 規約を計測するのは**選ぶため**ではなく、**下流の結論が規約の選択にどれだけ依存するかを測るため**である。判定は次で固定する。

- 3 規約の間で、core metric（水平線別の中央超過、IC、trap 率）の**符号がひとつも反転しない**なら、規約の選択は結論に効かない。B を採用し、感度は付記に留める
- ひとつでも符号が反転するなら、**B を採用したうえで、その metric を読む全ての結論に 3 規約の幅を併記する**。幅を消すために規約を選び直さない
- B の母集団指数が cohort の 30% 未満の生存銘柄でしか作れない水平線があれば、その水平線では B を成立させず、A と C の両側 bracket に残す

## 5. 停止条件

- `tender_offer_exit_values` に無い退出で、最終終値がスクイーズアウト前の希薄化価格である疑いが 5% を超える行に出た場合、実値化を止めて対価の取得（issue #909 段階 3）を先に行う
- 規約 B の母集団指数が、`in_population` の定義変更で cohort 間比較不能になる場合は中止し、指数定義を先に固定する
- 実装後、既存の `resolved` 行および `resolved_failure_exit` 行の値が 1 行でも変わったら中止して原因を先に直す

## 6. 解釈の限界

- 3 規約はいずれも「買収されたと分かる前の判断」を再現しない。退出は事後にしか分からないので、この較正は**実現した過去の分布**であって、買収を織り込んだ将来 E[r] ではない
- `株式の併合` 単独の退出は対価が別途開示される場合があり、最終終値が実現額と一致しない。issue #909 段階 3 が被覆を広げるまで、この群は対価不明として記録する
- 買収は規模と割安さに偏る（issue #909 の実測では規模の勾配のみ明確で、割安側はむしろ落ちにくい）。規約の選択はこの偏りを直さない
