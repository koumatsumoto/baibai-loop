# carry の株数項を自己株控除後で測り直す — 事前登録

価値tier: T1 — carry は E[r] の 2 成分の一方で、株数項の clip 幅 5%/年 は reversion 項の上限と同じである。株数項が測っている年がずれていれば、順位を単独で決めうる誤差が入る。

## 1. 固定する問いと非盲検性

E[r] の carry は `dividend_yield + clip(-net_share_change_yoy, ±5%)` で、株数項は**発行済株式総数**の前年比である。日本の自社株買いは取得した株式を自己株式へ入れるだけで、発行済株式総数は消却するまで減らない。

**著者は盲検ではない。** issue #904 の集計で以下を既に見ている。

- EDINET 自己株券買付状況報告書と突合すると、実買付が控除後株数の 1% 以上だった 556 期を、控除後差分は 95.3% 捉え、発行済差分は **36.3%** しか捉えない
- 全期間 20,816 会計年度対のうち、控除後だけが 1% 以上縮んだ期が 2,557 件（12.28%）、発行済だけが落ちた期（消却年）が 249 件（1.20%）
- clip 後の carry 差は p90 で 1.54pt/年、p99 は上限に張り付く

これらは**「2 つの量は別の年に動く」という事実**であり、どちらが forward 実現をよく説明するかについては何も言っていない。消却は取得より強い commitment signal でありうるので、現行が劣るとは断定できない。本書を commit するまで、`tradable_share_change_yoy` を forward return と結んだ IC・分位別実現・trap 判定を一切計測しない。cohort 別の非 null 率、2 軸の相関、欠損の重なりは outcome-free として確認してよい。

この study が答える問いは「carry の株数項をどちらで測るか」である。clip 幅、取得枠の残存（#833）、配当項の定義は評価しない。

## 2. 測る量

`tradable_share_change_yoy` = 自己株控除後株数の前年比。分子は `capital_basis.shares_ex_treasury`、分母は同じ前年行に `_shares_excluding_treasury` を当てたもの。既存 `net_share_change_yoy` と**同じ前年行**を使うので、両者の差は株数概念だけである。

自己株式数が観測できない行は答えない（J-Quants は自己株式 0 株を空欄で返す行があり、0 で埋めると自己株ゼロを捏造する）。したがって新軸は旧軸より被覆が狭い。

## 3. 比較の母集団（**両軸が非 null の行に限る**）

被覆が違う 2 軸をそれぞれの全数で比べると、標本選択の差が信号の差に化ける。**比較は両軸が非 null な行だけで行う。** 旧軸のみ非 null の群は「新軸が答えられない行」として件数と分位分布だけを併記し、優劣の判定には使わない。

母集団・窓・authority 規則は [`estimate-calibration.md`](../../../docs/reference/estimate-calibration.md) に従う。水平線は 3y と 5y。

## 4. 仮説と判定

| | 内容 |
| --- | --- |
| H1 | 控除後の減少は発行済の減少より forward 実現をよく説明する |
| H2 | 2 つを分離した合成（取得年と消却年を別軸として持つ）がどちらの単独よりよい |
| H3 | どちらでもない。現行を維持する |

**採否基準（issue #904 のものをそのまま固定する）**

- 3 窓すべてで符号が一致し、既存軸に対する増分が control trap を通ること
- `dividend_yield` control で trap にならないこと（`share_count_reduction_streak` は過去にここで negative になっている）
- 上記を満たさなければ H3 とし、fact は panel に残して close する

窓は `estimate-calibration.md` の authority が定める design / holdout / confirm の 3 つを使い、**事後に窓を選び直さない**。

## 5. 停止条件

- 両軸が非 null な行が、いずれかの水平線で cohort 中央値の 30% を下回る場合、その水平線では判定せず件数だけ報告する
- 2 軸の相関が 0.95 を超える場合、比較する意味が無いので H3 とする
- 実装後、既存の `resolved` forward 行または `net_share_change_yoy` の値が 1 行でも変わったら中止して原因を先に直す

## 6. 解釈の限界

- 控除後株数は「市場が値付けできる株式数」であって現金還元額ではない。第三者割当や新株予約権の行使でも動く
- 自己株式の**処分**（売出し・ストックオプション充当）は控除後株数を増やすので、取得と処分を同じ年に行った会社では相殺される。EDINET の月次買付株数はこの分離を持つが、本 study は panel の株数差分だけで測る
- 消却は取得の 1〜数年後に来るので、2 軸は**同じ事象を違う年に記録する**。水平線 3y / 5y ではその遅れが窓の内側に入りうる。H2 が採られる場合、この遅れの扱いを別途事前登録する
