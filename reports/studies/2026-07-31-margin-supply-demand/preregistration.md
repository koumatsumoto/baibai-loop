# 信用需給 4 軸の採否基準 — 事前登録

## 0. 事前登録（計測を実行する前に commit する）

信用取引週末残高から 4 軸を作った。この軸を rules（gate / ranking / E[r]）へ入れてよいかの基準を、**panel 計測を実行する前に**ここで固定する。

### 対象の軸と仮説方向

方向は実装の `AXES` に既に宣言してある（`direction=-1` = 低いほど良い）。ここでは何を測るかを言葉で固定する。

| 軸 | 定義 | 仮説 |
| --- | --- | --- |
| `margin_long_to_adv` | 信用買い残 ÷ 20 日平均出来高（株数） | 買い残が出来高の何日分も積み上がった銘柄は、戻り売り圧力が将来リターンを削る |
| `margin_long_share` | 買い残 ÷（買い残 + 売り残）、貸借銘柄のみ | 買い方に偏った銘柄は混雑しており、劣後する |
| `margin_long_delta_26w` | 半年の買い残変化 ÷ 発行済株式数 | 買い残が減った後の銘柄は、投げが済んでいる分だけ有利 |
| `margin_std_long_share` | 制度買い残 ÷ 信用買い残 | 6 か月の期日を持つ overhang が多いほど劣後する |

### 採否基準

**軸を rules へ入れる条件は、次の 3 つを同時に満たすことである。**

1. **符号の一貫性**: 1y と 3y の両方で、decile spread（最良 decile と最悪 decile の median excess の差）が仮説方向と同符号であること。
2. **時間 2 分割での再現**: cohort を前半・後半へ 2 分割し、両方で 1. の符号が一致すること。片方だけで出る効果は採らない。
3. **効果量**: 1y の decile spread が絶対値で 3pt 以上であること。統計的有意性は判定に使わない（月次 cohort は forward 窓が重なり独立でないため）。

**満たさない軸は rules へ入れない。** その場合も report は残し、flag は「閾値で立てる warning」ではなく「文脈として読む数値」へ格下げする。

### 交互作用の検定（トラップ仮説の直接検定）

軸単体の効果とは別に、本 issue の主目的である「割安に見えて混雑している銘柄」を直接検定する。

E[r] 上位 decile の中を `margin_long_to_adv` の上位・下位で 2 分し、両群の forward median excess を比較する。**上位（混雑側）が下位に劣後すれば、混雑バリュートラップは実在する。** この検定は軸を rules へ入れる条件とは独立で、成立すれば OP3 の narrative へ「割安だが混雑している」という文脈を出す根拠になる。

### 先に開示する限定

- **盲検ではない。** 実装中に 2026-07-24 断面の分布（`margin_long_to_adv` 中央値 1.43 日分・p90 15.8 日分）を見ている。ただし forward return との関係は一切見ていない。
- **外部の学術結論を輸入しない。** 週次信用残の予測力を示す研究と、長期では informed でないとする研究の双方が存在する。どちらも採否の根拠にせず、自 panel・自 horizon の計測だけで判定する。
- **3y は cohort 数が少ない。** 10 年の履歴でも 3y 満期済み cohort は 44 件で、forward 窓が重なるため独立標本ではない。cohort 数を標本数として読まない。
- **`margin_long_share` の母集団は貸借銘柄に限られる。** 信用銘柄（2026-07-24 の保存行で 1,552/4,249）は貸株が無く空売り残が構造的にゼロなので、この軸の cross-section には現れない。他の 3 軸とは母集団が違う。
- **分割を跨いだ窓の軸は None になる。** 26 週窓に分割を含む銘柄は実 store で 148（3.3%）。これらはその軸の母集団から落ちる。

### この基準を採る理由

閾値を「IC が有意」に置く形も考えたが採らない。月次 cohort は forward 窓が重なり独立でないので、p 値は標本数を過大に見積もる。decile spread の符号一貫性と時間 2 分割は、独立性を仮定せずに「別々の期間で同じ向きに出るか」を直接問う。

## 1. 対象

拡張 grid（2019-11-29〜、80 cohort）の 1y / 3y。週次残高は 10 年分を backfill し、各 cohort の asof で公表済みの最新残高日を join する。

## 2. 計測

10 年分の週末残高（507 balance date・2,064,052 行、要求 520 週のうち 13 週は取引所が公表せず 0 行として記録）を取り込み、80 cohort の panel を再構築して評価した。

decile spread は「良い側 decile の median excess − 悪い側の同値」で、良い側は宣言した direction で決まる。仮説どおりなら **正**になる。

| 軸 | horizon | cohort | spread 中央値 | 勝率 | 前半 / 後半 |
| --- | --- | ---: | ---: | ---: | --- |
| `margin_long_to_adv` | 1y | 68 | **+0.0978** | 0.74 | +0.086 / +0.102 一致 |
| | 3y | 44 | **+0.3093** | 0.98 | +0.306 / +0.353 一致 |
| `margin_long_share` | 1y | 68 | −0.0559 | 0.15 | −0.056 / −0.058 一致 |
| | 3y | 44 | −0.1271 | 0.02 | −0.131 / −0.125 一致 |
| `margin_long_delta_26w` | 1y | 68 | −0.0102 | 0.43 | −0.024 / +0.005 **割れ** |
| | 3y | 44 | +0.0073 | 0.50 | −0.002 / +0.091 **割れ** |
| `margin_std_long_share` | 1y | 68 | **+0.0450** | 0.76 | +0.033 / +0.050 一致 |
| | 3y | 44 | **+0.1386** | 0.91 | +0.117 / +0.198 一致 |

### 交絡の検定（事前登録に無い追加検定）

`margin_long_to_adv` は分母が出来高なので規模・流動性の代理変数になり得る。交絡候補を 1 つに絞らず、相関の強い順に当てる。

| 交絡候補 | `margin_long_to_adv` との順位相関（80 cohort 中央値） |
| --- | ---: |
| 出来高（`avg_turnover_oku`） | −0.428 |
| **時価総額（`market_cap_oku`）** | **−0.648** |

各 cohort を候補の quintile へ層別し、同じ帯の中で軸の上下半分を比較した。

| horizon | 層別なし | 出来高 quintile 内 | **時価総額 quintile 内** |
| --- | ---: | ---: | ---: |
| 1y | +0.0327（0.74） | +0.0449（0.72） | **+0.0089（0.54）** |
| 3y | +0.1742（0.93） | +0.1793（0.93） | **+0.0500（0.77）** |

**時価総額を固定すると 1y の効果はほぼ消える**（勝率 0.54 はコイン投げ）。事前登録の統計量（decile spread）で見ても 1y は +0.098 → −0.001 と符号を失う。

この統制が過剰でないことは、同じ層別を他の軸へ当てて確かめた。`per_trailing` は raw IC の 1.05 倍、`pbr` 0.99 倍、`ocf_yield` 0.94 倍、`dividend_yield` 0.98 倍、`er_annual` 0.91 倍を保持し、落ちるのは `margin_long_to_adv`（0.01 倍）だけである。

採用へ残る `margin_std_long_share` にも、同じ「相関の強い順」を適用する。

| 順 | 統制 | 軸との相関 | 1y（勝率） | 3y（勝率） |
| ---: | --- | ---: | ---: | ---: |
| — | 層別なし | — | +0.0231（0.81） | +0.0610（0.91） |
| 1 | `dividend_yield` | +0.182 | **+0.0063（0.60）** | +0.0286（0.80） |
| 2 | `per_trailing` | −0.157 | **+0.0048（0.62）** | +0.0325（0.84） |
| 3 | 時価総額 | −0.144 | +0.0327（0.85） | **+0.0851（1.00）** |
| 4 | 出来高 | −0.138 | +0.0250（0.82） | +0.0684（0.91） |
| 5 | 株価水準 | −0.131 | +0.0201（0.81） | +0.0508（0.89） |
| 6 | 60 日モメンタム | +0.110 | +0.0152（0.75） | +0.0527（0.91） |
| — | 業種 33（厳密） | — | +0.0110（0.78） | — |
| — | 規模 + 出来高（偏順位相関） | — | +0.0541（0.90） | +0.1029（1.00） |
| — | 実現ボラティリティ 60 日 | — | +0.0158（0.83） | +0.0702（0.93） |

**最も強い交絡はバリュー系（`dividend_yield` / `per_trailing`）で、これを固定すると 1y はほぼコイン投げになる。** ただしこれはこの軸に固有の現象ではない。同じ統制を他の軸へ当てると `pbr` は raw IC の 0.60 倍、`per_trailing` 0.31 倍、`er_annual` 0.31 倍、`ocf_yield` 0.20 倍まで落ち、`margin_std_long_share` の 0.30 倍はその帯の中にある。バリュー系の統制は**あらゆる軸を 2〜5 倍減衰させる共有分散**であって、`margin_long_to_adv` が見せた 0.01 倍のような「その軸だけが消える」形ではない。

したがってこの軸について言えるのは「規模・流動性・株価水準・業種・モメンタム・ボラティリティのいずれの代理でもない」であって、**「どんな統制にも崩れない」ではない**。バリュー複合と分離した固有寄与は 1y では小さく、3y でのみ明確に残る。

### 混雑バリュートラップの交互作用

E[r] 上位 decile を `margin_long_to_adv` で 2 分し、混雑側 − 非混雑側の median excess を出した。

| horizon | cohort | 差の中央値 | 混雑側が劣後した cohort の割合 |
| --- | ---: | ---: | ---: |
| 1y | 68 | −0.0078 | 0.53 |
| 3y | 44 | −0.0328 | 0.64 |

**この分割軸は本 report が規模の代理と結論した `margin_long_to_adv` なので、差の一部は規模差である。** 割安 decile を時価総額だけで 2 分すると差は 1y −0.019・3y −0.068 と報告値より大きく、規模を固定した中で混雑度で分けると 1y −0.011・3y −0.025 になる。3y の大きさの約 4 分の 3 は規模を固定しても残るので数値自体は誤りではないが、「混雑が劣後を生む」と読むには規模と分離した再設計が要る。

## 3. 判定

事前登録した 3 条件（1y/3y の符号一致・時間 2 分割での再現・1y で 3pt 以上）に照らす。

| 軸 | 判定 |
| --- | --- |
| `margin_std_long_share` | **採用**。3 条件を満たし、時価総額を固定しても効果が残る（むしろ強まる） |
| `margin_long_to_adv` | **不採用**。素の 3 条件は満たすが、時価総額を固定すると 1y の符号が消える（下記） |
| `margin_long_delta_26w` | **不採用**。時間 2 分割で符号が割れ、効果量も 1pt 未満 |
| `margin_long_share` | **不採用**（下記の限定つき） |

### `margin_long_to_adv` — 素の基準は満たすが、規模の代理だった

素の decile spread は 1y +0.098 / 3y +0.309 と 3 条件をすべて満たす。しかし時価総額との順位相関が −0.648 あり、時価総額を固定すると 1y の効果は +0.009（勝率 0.54）まで落ちる。事前登録の統計量では符号すら失う。この軸が測っていたものの大半は「小型株かどうか」である。

**事前登録に交絡検定の手順を書かなかったことが、この誤りを許した。** 最初に当てた統制（出来高）では効果が残ったのでそこで止めており、より強い交絡候補を試していない。統制は思いついた 1 つではなく、相関の強い順に列挙して当てるべきだった。次の事前登録では交絡候補の列挙と適用順を条件へ含める。

建玉の厚み自体に意味が無いと結論づけたわけではない。規模と分離した形（例: 同規模帯内での相対値、または時価総額で正規化した残高）で測り直す余地はあり、それは別の事前登録を要する。

### `margin_long_share` — 仮説と逆向きに強く出た

事前登録した仮説は「買い方に偏った銘柄は混雑しており劣後する」（`direction=-1`）。実測は 1y/3y とも**一貫して逆**で、勝率 0.15 / 0.02 は「効果が無い」ではなく「逆向きに強い」ことを示す。

この軸は貸借銘柄に限られ、買い残比率が低い＝空売り残が相対的に厚い状態を意味する。空売り残の厚い銘柄が劣後するのは空売り情報仮説と整合し、実測はその向きに一致している。

**それでも本 report では採用しない。** 計測結果を見てから符号を反転させるのは、事前登録が防ぐために存在する行為そのものである。この効果を使うなら、「空売り残の厚さが劣後を予測する」という**別の仮説として新たに事前登録し、独立に検定する**。ここで記録するのは「仮説は棄却された」ことと「逆向きの一貫した効果が観測された」ことの 2 つで、後者は次の事前登録の動機であって根拠ではない。

### 交互作用は 3y で弱く見える

混雑側の劣後は 3y で −3.3pt・64% の cohort に現れるが、1y は −0.8pt・53% とほぼコイン投げである。**「割安かつ混雑」を単独の警告として立てるには弱い。** 閾値 flag は立てない。

### この結果が意味しないこと

- **採用 = rules を変えた、ではない。** 採用は「rules への参入を事前登録つきの別 issue で提案してよい」段階に達したという意味である。gate / ranking / E[r] の変更は本 report では行わない。
- **3y の 44 cohort は独立標本ではない。** forward 窓が重なる月次 cohort なので、勝率を確率として読まない。
- **3y の時間 2 分割は再現テストとして機能していない。** 前半の窓は 2019-11〜2024-08、後半は 2021-09〜2026-06 で暦の 6 割が重なる。事前登録した条件 2 は 1y（重なり 24%）でのみ実質的な検定であり、3y の「両半分で符号一致」はほぼ自動的に満たされる。次の事前登録では、重なりの無い窓での分割を条件にする。
- **10 年は 1 つの市況しか含まない可能性がある。** 2019-11 以降の cohort は大部分が金融緩和局面で、引き締め局面での挙動は測れていない。
- **4 軸の数値は API 応答には載るが、まだ画面には出ていない。** 判断面への列追加は残作業である。
