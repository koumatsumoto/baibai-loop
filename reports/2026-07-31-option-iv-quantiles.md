# 日経225オプション IV の実測分位

閾値をコードに埋めないために、水準の高低を判断する基準を実測から出す。

## 1. 標本の取り方

2018-01-01〜2026-07-31 を 4 営業日ごとに走査し、チェーンが返った 524 営業日。再現と延長は生成スクリプトで行う。

```
uv run python tools/research/option_iv_sample.py --start 2018-01-01 --end 2026-07-31 --step 4 --out <csv>
```

刻みは 2 つの偏りを同時に避ける。**暦の等間隔**なので、変動の大きい時期が「憶えている日」として過大に入り上側分位を押し上げることがない。**5 の倍数でない**ので曜日が巡回する（Mon 100 / Tue 107 / Wed 107 / Thu 105 / Fri 105）。5 営業日刻みだと標本が全て月曜になり、週末を跨いだ分散を織り込む分だけ IV が高く出る。実測では月曜固定標本の `iv30` は p90 = 28.4 / p99 = 55.3 で、曜日を散らすと 26.9 / 48.5 まで下がった。スクリプトは 5 の倍数の刻みを拒否する。

全営業日は取っていない。1 日 1 万行のチェーンを 1 日 1 回取得するので全数は数時間かかり、分位の推定に必要なのは範囲の被覆であって全数ではない。

## 3. 読み方

**`iv30` の水準**は分位で読む。p50 = 18 前後が平時、p75 = 22 で警戒、p90 = 27 を超えると市場が明確に身構えている。上位 5 日はすべて 2020 年 3〜4 月（65.9 / 62.9 / 51.4 / 49.5 / 48.5）で、p99 = 48.5 は COVID 崩落の水準である。

**2026 年は期間中で最も高い。** 中央値 29.4 は 2020 年（18.7）を上回り、平時（2019 年 14.4 / 2023 年 16.2）の約 2 倍にあたる。2020 年は最大値が突出する一方で中央値は 18.7 にとどまる——崩落は数週間で、年の大半は平時だった。2026 年はその逆で、突出した日はなくとも高い水準が年を通じて続いている。

**`skew` は 517 日すべて正だった。** p05 でも +2.2 で、日経オプションは恒常的に、ATM より 5% 下の行使価格に高いボラティリティを付ける。したがって負の skew は「稀な局面」ではなく、この標本では**観測されなかった**。0 に近づくことが下方警戒の後退を意味する。

**`term` は中央値 +0.1 で、46% の日が逆転している。** 逆転そのものは平常であり、それ自体はパニックを意味しない。読むべきは深さで、p05 の −4.2 まで開くのは目先の警戒が先の見通しを大きく上回る局面に限られる。2024 年以降は中央値が負に転じており（2024 −0.26 / 2025 −0.36 / 2026 −0.71）、目先が重い状態が常態化している。

## 4. 出ない日がある

**`iv30` は 437/524 日（83%）でしか出ない。** `opt_225` は月次限月しか持たないので、SQ 直後は手前 2 限月が 30 日を挟まない日が続く。定数満期化はその場合に値を作らない。欠測は散発ではなく SQ 周期に沿った連続した数日である。

**`skew` と `term` は 517/524 日（99%）。** 出なかった 7 日（2019-02-01 / 2020-02-06 / 2020-04-08 / 2020-04-30 / 2020-06-03 / 2021-02-26 / 2022-06-29）は、ATM 前後 ±10% の同一行使価格でプットとコールの IV が中央値 15 ポイント超食い違った日である。プットコールパリティ上この 2 つは一致すべきなので、これは市場の状態ではなく出所側の不整合であり、差を取る読みは出せない。`iv30` はプットとコールの平均なので誤差が相殺し、これらの日も値を持つ。

## 5. この結果が意味しないこと

- **買い時を告げるものではない。** #668 の計測で、下落局面でも通過候補数は広がらない（60d ≤ −5% で 396 対 +5% 超で 381）ことが確認されている。律速は候補でなく確信であり、IV はその確信を支える観測であって、建てる / 建てないを決める規則ではない。
- **分位は固定ではない。** 標本は 8.5 年で、この期間に含まれる大きな崩落は COVID 1 回だけである。より深い崩落が来れば上側の分位は動く。
- **4 営業日ごとの標本である。** 単日の突出は取りこぼしうるので、p99 と最大値は実際の極値より低い。
- **`skew` と `term` の水準は限月構成に依存する。** 満期 7 日未満の限月を除くため、SQ 直後は参照する限月が入れ替わり、その日の値は前後と不連続になりうる。
