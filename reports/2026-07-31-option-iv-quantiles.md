# 日経225オプション IV 3 系列の振る舞い

3 系列を macro context で読む前に、**いつ値が出ないか・何に依存するか・どの範囲に収まるか**を実測で固定する。

水準が高いか低いかの判断は他の系列と同じく **reading の `percentile`（10 年窓・全営業日）を正とする**。ここに載せる分位はその第二の物差しではない。同じ母集団を別の切り口で見せるためと、以下の性質を数値で示すためにある。

## 1. 測定の出どころ

数値は 2 つの資料から出る。**どちらから出たかを節ごとに明示する。**

**正本 store（全営業日）。** 2016-08-04〜2026-07-31 の全取引日 2,440 日。3 系列を全期間取得して `data/indicators/macro.sqlite` に入れたもので、§2・§3・§4 の出現率と空白の数値はここから出る。出荷されたコードの出力そのものなので、読みの再現に別の実装が挟まらない。始点は購読窓の縁（運用日から 10 年 rolling）の数日内側に置いてある。

```
uv run baibai-engine macro refresh jp.n225_iv_30d jp.n225_iv_skew jp.n225_iv_term \
    --start 2016-08-04 --end 2026-07-31
```

**標本 CSV（4 営業日刻み・524 日）。** [`reports/data/option-iv-sample.csv`](./data/option-iv-sample.csv)。store は集計後の 3 値しか持たないので、**出所の put/call 食い違い（`near_gap` / `far_gap`）と限月位置（`near_days` / `far_days`）を持つのはこの標本だけ**である。§4 の回帰と §5 のギャップ分布はここから出る。

```
uv run python tools/research/option_iv_sample.py --start 2018-01-01 --end 2026-07-31 --step 4 \
    --out reports/data/option-iv-sample.csv
```

刻みは 2 つの偏りを同時に避ける。**暦の等間隔**なので、変動の大きい時期が「憶えている日」として過大に入り上側分位を押し上げることがない。**5 の倍数でない**ので曜日が巡回する（Mon 100 / Tue 107 / Wed 107 / Thu 105 / Fri 105）。5 の倍数を拒む理由は曜日そのものでなく**限月位置**である。限月は月次なので満期日数は 7 日周期を持ち、4 営業日刻みの下では曜日を固定すると満期日数 mod 7 まで固定される——標本が SQ 周期の 1 剰余類だけを引くことになる。スクリプトは 5 の倍数の刻みを拒否する。

**2 つは全営業日で一致する。** 標本 524 日 1,384 値を store と突き合わせて差は 0（最大絶対差 0.0）。標本は出所が緊急取引証拠金の日にチェーンを 2 部返すことを知る前に取ったので、混ざった日があれば store と食い違う。食い違いが 1 つも無いことが、**524 日のどれも 2 部返しの日でなかった**ことを示している。

## 3. 読み方

**`iv30` の分位は現在の地合いでは弁別しない。** 全期間では定義上 p75 超が 25%、p90 超が 10% だが、2026 年の 116 観測では **p75 超が 100%、p90 超が 86%** である。「p90 を超えたら警戒」は 2016-2025（p90 超 5.3%）の物差しで、2026 年に当てるとほぼ毎日鳴る。上位 5 日はすべて 2020 年 3 月の 1 週間（73.54 / 72.85 / 69.62 / 68.89 / 65.95、3/13〜3/19）で、p99 = 40.14 より上はほぼ COVID 崩落の 3 週間で占められている。

**2026 年は期間中で最も高い。** 中央値 29.40 は 2020 年（19.12）を上回り、平時（2019 年 14.38 / 2023 年 16.48）の約 2 倍にあたる。2020 年は最大値が突出する一方で中央値は 19.12 にとどまる——崩落は数週間で、年の大半は平時だった。2026 年はその逆で、突出した日はなくとも高い水準が年を通じて続いている（116 観測すべてが全期間 p75 = 20.94 を超える）。ただし 7 か月の部分年 116 観測と通年 200 前後の比較である。

**`skew` は 2,004 日すべて正だった。** 最小でも +0.24 で、日経オプションは恒常的に、ATM より 5% 下の行使価格に高いボラティリティを付ける。したがって負の skew は「稀な局面」ではなく 10 年で**観測されなかった**。0 に近づくことが下方警戒の後退を意味し、最小値の 2020-03-11（0.24）は崩落の最中で ATM 自身が跳ね上がり非対称が潰れた日である。

**`term` は中央値 +0.26 で、40.6%（981/2,418 日）が逆転している。** 逆転そのものは平常であり、それ自体はパニックを意味しない。読むべきは深さで、p05 の −3.22 より深く開く 120 日は目先の警戒が先の見通しを大きく上回る局面に限られる（最深は 2024-08-05 の −14.84。この日のチェーンは 6,022 行・重複契約 0 行で、値は市場の状態である）。

2024 年以降は中央値が負に転じている（2024 −0.21 / 2025 −0.23 / 2026 −0.84）。**この drift は限月構成の副作用ではないが、示せるのはそこまでである。** 満期帯の情報は標本にしかないので以下は標本から——満期帯を固定して比べると 2026 年の 21〜27 日帯は −0.12 で、2024 年（−0.46）・2025 年（−0.33）より浅い。構成効果は raw の drift と逆向きに働いており、生の値はむしろ控えめということになる。一方で 2026 年は満期構成が標本中で最も偏った年でもある（30 日を挟む割合 74%、他年は 81〜87%）。年あたり 33〜64 観測で 0.5 ポイントの差なので、弱い観測として扱う。

## 4. 出ない日がある

**`iv30` と `skew` は 2,024/2,440 日・2,004/2,440 日（83.0% / 82.1%）でしか出ない。** どちらも手前 2 限月が 30 日を挟むことを要する。`opt_225` は月次限月しか持たないので、SQ 直後は手前限月が既に 30 日超になる——標本で確かめた範囲では、出ない日の手前限月は**すべて 31〜39 日先**である。この状態で 30 日の値を作るにはチェーンが値付けしていない満期へ外挿するしかないので、作らない。

**欠測は散発ではなく SQ 周期に沿った連続した数日である。** store の観測列から直接測ると空白は 507 回、中央値 3 日、**最長 19 暦日**（2019-04-26 → 2019-05-15、GW と重なった回）。次いで 16 日が 2 回（いずれも年末年始）。reading rules の staleness はこの構造に合わせて override してあり、警告が立つ 24 日には実測最長に対して 5 日の余裕がある。

**`term` は 2,418/2,440 日（99.1%）** で、限月が 2 つあれば出る。

**差を取る 2 つが出ない日が 22 日ある。** うち 20 日は水準が出ている（＝限月は 30 日を挟んでいる）ので、ATM 前後 ±10% の同一行使価格でプットとコールの IV が中央値 12 ポイント超食い違ったことによる。プットコールパリティ上この 2 つは一致すべきなので、出所側が両側を揃った基準で出せていない。残る 2 日（2020-03-09 / 2024-08-06）は**空白と食い違いが同じ日に重なった日**で、3 系列とも空になる——10 年でこの 2 日だけである。

**食い違いは荒れた年に集中する。** 20 日の年別内訳は 2018 年 2 / 2019 年 2 / **2020 年 9** / 2021 年 3 / 2023 年 1 / 2026 年 3 で、COVID 崩落の 2 か月だけで 8 日を占める。

**第 2 限月だけが壊れる日が実際にある。** 2024-08-06（暴落翌日）は手前限月のギャップが 10.21 で基準内だが、第 2 限月が 15.06 だった。手前だけを検査していれば通過し、**壊れた第 2 限月から引いた期間構造が出ていた**。検査を両限月に掛けるのはこのためである。

**水準は暴落の週ほど出にくい。** 2024-08-05（日経 −12.4%）の時点で手前限月は 4 日先（7 日未満で除外）、次は 39 日先だったので、`iv30` と `skew` は 08-05 から 08-09 まで空く。SQ 直前に相場が壊れると 30 日定数満期は必ず成り立たなくなる。この週は `term` が全期間最深の −14.84 を出して代わりに鳴っている。

**食い違いで `skew` / `term` が空いた日も `iv30` は残す。** ATM ではプットとコールが、出所が基準にした価格の誤差に対して同じだけ反応するので、誤差は両者を反対向きに離し、平均は元の位置に残る。`iv30` の**近傍からのずれ**——標本上でその日を挟む前後 2 点ずつ計 4 観測の中央値との差——を手前限月の符号付きギャップに回帰すると、433 観測（両端 4 点は近傍を取れない）で**傾きは +0.04（標準誤差 0.04、95% 区間 −0.03〜+0.11）**。片側だけがずれるならギャップの半分が平均に乗るので傾きは ±0.5 になるはずで、それは **13 標準誤差**離れている。対称（傾き 0）は区間の中にある。

（相関の符号だけでは判別できない。`near_gap` は put − call なので、壊れているのが put 側なら片側でも符号は正になる。区別するのは傾きの大きさである。）

（最大の食い違いだった 2020-04-08 は put 46.53 / call 28.01 に対し平均 37.27 で、**前後の取引日**の 36.72 / 36.30 の間に収まる。この 3 日は連続する取引日なので 4 営業日刻みの標本には無く、出所から直接取得して確かめた。標本内の前後は 48.46 / 32.71 で、COVID 期の変動が大きすぎて単独では判定に使えない。）

ギャップ帯ごとに切っても同じで、傾きは |gap| ≤ 3 で +0.02（n = 294）、3〜6 で +0.14（n = 91）、6〜12 で +0.16（n = 41）。±0.5 の近い側までそれぞれ 5.7 / 4.0 / 4.6 標準誤差ある。

**ただしゲートが落とす日そのものでは検定できていない。** 標本に入っているのはそのうち 7 日で、その 7 日だけで測ると傾きは **−0.29（標準誤差 0.12）** で、−0.5 は 1.7 標準誤差しか離れていない——棄却できない。7 点しかなく、うち 5 日は水準が数日で 10 ポイント動く局面（COVID 期・2021-02）なので、近傍からのずれの大半は出所の食い違いでなく市場自身の動きである（|gap| > 12 の 7 日は絶対ずれの中央値 15.2%、全 433 日では 6.5%）。つまり「平均は誤差を生き延びる」は**測れる範囲では成り立つが、最も食い違いの大きい日についてはこの標本が肯定も否定もしていない**。それでも `iv30` を残すのは落とすと最も読みたい日が空くからで、**その日の誤差が最悪でギャップの半分（この 7 日なら 6〜10 ポイント）になりうることを承知の上の選択**である。該当する 20 日の水準を単独で読まず、必ず前後の営業日と並べる。`skew` / `term` が空いていることがその印になる。

## 5. この結果が意味しないこと

- **買い時を告げるものではない。** #668 の計測で、下落局面でも通過候補数は広がらない（60d ≤ −5% で 396 対 +5% 超で 381）ことが確認されている。律速は候補でなく確信であり、IV はその確信を支える観測であって、建てる / 建てないを決める規則ではない。
- **分位は固定ではない。** 窓は 10 年で、この期間に含まれる大きな崩落は COVID 1 回だけである。より深い崩落が来れば上側の分位は動く。水準判断の正本を reading の `percentile` に置くのはこのためでもある。
- **`iv30` は曜日ごとに出やすさが違う。** 月曜 71% に対し水曜 93%（30 日を挟む条件が限月位置と連動するため）。全営業日を取っているので分位に偏りは入らないが、「昨日の値と比べる」読み方は曜日によって比較対象の齢が変わる。
- **標本が全数と一致することは確かめたが、標本にしか無い列は確かめようがない。** 緊急取引証拠金が発動した日、`opt_225` は清算値算出時と発動時の 2 部を返す（実測: 2016-08-02 は 4,380 行 = 1 契約 2 行）。読むのは清算値算出時の部だけだが、標本を作ったときこの選別は入っていなかった。3 系列の値は store と 1,384 値すべて一致したので**標本 524 日に 2 部返しの日は無い**が、混ざった日は基準ギャップをほとんど動かさない（実測 0.95 対 0.88）ので、仮に将来 2 部の日を含む標本を作っても `near_gap` / `far_gap` の分布からは気づけない。標本を取り直すときは選別済みのコードで取る。
- **`skew` と `term` は恐怖が高い日ほど検閲されている。** ゲートが落とした 20 日の `iv30` 分位は **16 日が p75 超**（基準 25%）・**10 日が p90 超**（基準 10%）で、うち 4 日は分位 1.00（2020 年 3 月の最上位帯）。出所の両側が食い違うのは荒れた日に多いので、これは設計上そうなる。したがって「`skew` は 2,004 日すべて正」は**検閲後の母集団についての主張**である——負に振れるとしたらまず崩落日で、その一部が抜けている。
- **`term` は 30 日満期化していない。** 2 限月の差そのものなので補間する第 3 の点がなく、手前限月がどこにあるかで意味が動く（`corr(手前限月日数, term) = +0.104`、満期帯別の中央値 −0.17〜+0.35）。`skew` は 30 日へ補間してあり、同じ相関は **−0.031**、満期帯別の中央値も 3.43 / 3.54 / 3.60 / 3.58 で単調でない。
- **`skew` / `term` を出さない基準は出所の食い違いの大きさで引いている。** 分布は標本の `near_gap` / `far_gap` 列にある。読みが軸にする手前限月は p50 = 1.72 / p90 = 5.78 / p95 = 8.07 / p99 = 12.43 / 最大 20.35、第 2 限月は p50 = 0.84 / p90 = 2.68 / p99 = 7.64 / 最大 14.13、両限月を混ぜると p50 = 1.21 / p90 = 4.25 / p99 = 10.88。境界の 12 は**手前限月の通常域の上端**として置いてある。ギャップが大きいほど skew は近傍から離れるが、それは 12 を境に始まるのではなく連続に強まる——境界は曲線上の 1 点であって折れ点ではない（この検定は現行のゲートが該当日の `skew` を空にするため、標本からは再現できない。ゲート前の同一窓の測定による）。
