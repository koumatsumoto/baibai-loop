# 日経225オプション IV の実測分位

閾値をコードに埋めないために、水準の高低を判断する基準を実測から出す。

## 1. 標本の取り方

2018-01-01〜2026-07-31 を 4 営業日ごとに走査し、チェーンが返った 524 営業日。標本は[`reports/data/option-iv-sample.csv`](./data/option-iv-sample.csv)にあり、本ドキュメントの数値はすべてこれ 1 本から出る。再現と延長は生成スクリプトで行う。

```
uv run python tools/research/option_iv_sample.py --start 2018-01-01 --end 2026-07-31 --step 4 \
    --out reports/data/option-iv-sample.csv
```

刻みは 2 つの偏りを同時に避ける。**暦の等間隔**なので、変動の大きい時期が「憶えている日」として過大に入り上側分位を押し上げることがない。**5 の倍数でない**ので曜日が巡回する（Mon 100 / Tue 107 / Wed 107 / Thu 105 / Fri 105）。

曜日を散らす理由は効果量ではなく検査可能性である。実測すると月曜プレミアムは小さい——`iv30` で中央値 +0.87 / p90 +0.52、`skew` は +0.06 / −0.05、`term` は −0.14 / +0.22。しかし 5 営業日刻みは標本を全て月曜に固定するので、**その偏りが小さいことを標本自身から確かめる手段がなくなる**。スクリプトは 5 の倍数の刻みを拒否する。

全営業日は取っていない。1 日 1 万行のチェーンを 1 日 1 回取得するので全数は数時間かかり、分位の推定に必要なのは範囲の被覆であって全数ではない。同じ窓を 2 回独立に取得して 524 日 × 3 系列が完全一致することは確認した。

## 3. 読み方

**`iv30` の水準**は分位で読む。p50 = 18 前後が平時、p75 = 22 で警戒、p90 = 27 を超えると市場が明確に身構えている。上位 5 日はすべて 2020 年 3〜4 月（66.0 / 62.9 / 51.4 / 49.5 / 48.5）で、p99 = 48.5 は COVID 崩落の水準である。

**2026 年は期間中で最も高い。** 中央値 29.4 は 2020 年（18.7）を上回り、平時（2019 年 14.4 / 2023 年 16.2）の約 2 倍にあたる。2020 年は最大値が突出する一方で中央値は 18.7 にとどまる——崩落は数週間で、年の大半は平時だった。2026 年はその逆で、突出した日はなくとも高い水準が年を通じて続いている。

**`skew` は 436 日すべて正だった。** 最小でも +0.24 で、日経オプションは恒常的に、ATM より 5% 下の行使価格に高いボラティリティを付ける。したがって負の skew は「稀な局面」ではなくこの標本では**観測されなかった**。0 に近づくことが下方警戒の後退を意味し、最小値の 2020-03-11（0.24）は崩落の最中で ATM 自身が跳ね上がり非対称が潰れた日である。

**`term` は中央値 +0.1 で、46%（242/523 日）が逆転している。** 逆転そのものは平常であり、それ自体はパニックを意味しない。読むべきは深さで、p05 の −4.1 より深く開くのは目先の警戒が先の見通しを大きく上回る局面に限られる（最深は 2024-08-05 の −14.8）。2024 年以降は中央値が負に転じている（2024 −0.26 / 2025 −0.36 / 2026 −0.71）。この 3 年で限月構成は変わっていない（後述）ので構成の副作用ではないが、年あたり 34〜64 日の標本で 0.5 ポイントの差であり、弱い観測として扱う。

## 4. 出ない日がある

**`iv30` と `skew` は 437/524 日・436/524 日（83%）でしか出ない。** どちらも手前 2 限月が 30 日を挟むことを要する。`opt_225` は月次限月しか持たないので、SQ 直後は手前限月が既に 30 日超になる——出ない 87 日の手前限月は**すべて 31〜39 日先**である。この状態で 30 日の値を作るにはチェーンが値付けしていない満期へ外挿するしかないので、作らない。欠測は散発ではなく SQ 周期に沿った連続した数日である。

**`term` は 523/524 日（99.8%）** で、限月が 2 つあれば出る。

**3 系列とも出なかった日は 0 日、`iv30` があって差が出なかった日は 1 日（2020-04-08）。** この日は ATM 前後 ±10% の同一行使価格でプットとコールの IV が中央値 20 ポイント超食い違った。プットコールパリティ上この 2 つは一致すべきなので、出所側が両側を揃った基準で出せていない日であり、差を取る読みは出せない。`iv30` はプットとコールの平均なので誤差が相殺し、この日も値を持つ。

## 5. この結果が意味しないこと

- **買い時を告げるものではない。** #668 の計測で、下落局面でも通過候補数は広がらない（60d ≤ −5% で 396 対 +5% 超で 381）ことが確認されている。律速は候補でなく確信であり、IV はその確信を支える観測であって、建てる / 建てないを決める規則ではない。
- **分位は固定ではない。** 標本は 8.5 年で、この期間に含まれる大きな崩落は COVID 1 回だけである。より深い崩落が来れば上側の分位は動く。
- **4 営業日ごとの標本である。** 単日の突出は取りこぼしうるので、p99 と最大値は実際の極値より低い。
- **`skew` の SQ 周期依存は残っている。** 30 日定数満期化は手前限月がどこにあるかへの依存を大きく減らすが、消しはしない。手前限月別の中央値は 4.03（7〜13 日）→ 3.90 → 3.76 → 3.61（28〜45 日）で、`corr(手前限月日数, skew) = −0.203`。0.42 ポイントの幅は四分位範囲 1.41 の約 3 割にあたる。
- **`term` は定数満期化していない。** 2 限月の差そのものなので、手前限月がどこにあるかで意味が動く（`corr(手前限月日数, term) = +0.106`、中央値 −0.17〜+0.35）。限月構成は年を通じてほぼ一定（手前限月の中央値 21〜22.5 日、30 日を挟む割合 74〜87%）なので年別比較は成立するが、単日の値を分位に当てるときはこの幅を織り込む。
