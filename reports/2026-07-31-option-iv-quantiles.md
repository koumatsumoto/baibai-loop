# 日経225オプション IV 3 系列の振る舞い

3 系列を macro context で読む前に、**いつ値が出ないか・何に依存するか・どの範囲に収まるか**を実測で固定する。

水準が高いか低いかの判断は他の系列と同じく **reading の `percentile`（10 年窓・全営業日）を正とする**。ここに載せる分位はその第二の物差しではない。store が 10 年窓を満たすまでの間に水準の当たりを付けるためと、以下の性質を数値で示すためにある。

## 1. 標本の取り方

2018-01-01〜2026-07-31 を 4 営業日ごとに走査し、チェーンが返った 524 営業日。標本は[`reports/data/option-iv-sample.csv`](./data/option-iv-sample.csv)にあり、本ドキュメントの数値はすべてこれ 1 本から出る。

```
uv run python tools/research/option_iv_sample.py --start 2018-01-01 --end 2026-07-31 --step 4 \
    --out reports/data/option-iv-sample.csv
```

刻みは 2 つの偏りを同時に避ける。**暦の等間隔**なので、変動の大きい時期が「憶えている日」として過大に入り上側分位を押し上げることがない。**5 の倍数でない**ので曜日が巡回する（Mon 100 / Tue 107 / Wed 107 / Thu 105 / Fri 105）。

5 の倍数を拒む理由は曜日そのものでなく**限月位置**である。限月は月次なので満期日数は 7 日周期を持ち、4 営業日刻みの下では曜日を固定すると満期日数 mod 7 まで固定される——標本が SQ 周期の 1 剰余類だけを引くことになる。月曜と他曜日の `iv30` 中央値差 +0.87 も曜日効果ではなくこの限月位置の差で、満期帯を揃えて比べると符号すら安定しない。スクリプトは 5 の倍数の刻みを拒否する。

全営業日は取っていない。1 日 1 万行のチェーンを 1 日 1 回取得するので全数は数時間かかり、必要なのは範囲の被覆であって全数ではない。

## 3. 読み方

**`iv30` の分位は現在の地合いでは弁別しない。** 標本全体では p75 超が 25%、p90 超が 10% だが、2026 年の 25 観測では **p75 超が 100%、p90 超が 84%** である。「p90 を超えたら警戒」は 2018-2025（p90 超 5%）の物差しで、2026 年に当てると毎日鳴る。上位 5 日はすべて 2020 年 3〜4 月（65.95 / 62.92 / 51.44 / 49.53 / 48.46）で、p99 = 48.46 は COVID 崩落の水準である。

**2026 年は期間中で最も高い。** 中央値 29.36 は 2020 年（18.73）を上回り、平時（2019 年 14.43 / 2023 年 16.15）の約 2 倍にあたる。2020 年は最大値が突出する一方で中央値は 18.73 にとどまる——崩落は数週間で、年の大半は平時だった。2026 年はその逆で、突出した日はなくとも高い水準が年を通じて続いている（25 観測すべてが標本 p75 = 21.80 を超える）。ただし 7 か月の部分年 25 観測と通年 50 前後の比較である。

**`skew` は 430 日すべて正だった。** 最小でも +0.24 で、日経オプションは恒常的に、ATM より 5% 下の行使価格に高いボラティリティを付ける。したがって負の skew は「稀な局面」ではなくこの標本では**観測されなかった**。0 に近づくことが下方警戒の後退を意味し、最小値の 2020-03-11（0.24）は崩落の最中で ATM 自身が跳ね上がり非対称が潰れた日である。

**`term` は中央値 +0.13 で、46%（237/517 日）が逆転している。** 逆転そのものは平常であり、それ自体はパニックを意味しない。読むべきは深さで、p05 の −3.91 より深く開くのは目先の警戒が先の見通しを大きく上回る局面に限られる（最深は 2024-08-05 の −14.84。この日のチェーンは 6,022 行・重複契約 0 行で、値は市場の状態である）。

2024 年以降は中央値が負に転じている（2024 −0.26 / 2025 −0.36 / 2026 −0.50）。**この drift は限月構成の副作用ではないが、示せるのはそこまでである。** 満期帯を固定して比べると 2026 年の 21〜27 日帯は −0.12 で、2024 年（−0.46）・2025 年（−0.33）より浅い——構成効果は raw の drift と逆向きに働いており、生の値はむしろ控えめということになる。一方で 2026 年は満期構成が標本中で最も偏った年でもある（30 日を挟む割合 74%、他年は 81〜87%）。年あたり 33〜64 観測で 0.5 ポイントの差なので、弱い観測として扱う。

## 4. 出ない日がある

**`iv30` と `skew` は 437/524 日・430/524 日（83% / 82%）でしか出ない。** どちらも手前 2 限月が 30 日を挟むことを要する。`opt_225` は月次限月しか持たないので、SQ 直後は手前限月が既に 30 日超になる——出ない 87 日の手前限月は**すべて 31〜39 日先**である。この状態で 30 日の値を作るにはチェーンが値付けしていない満期へ外挿するしかないので、作らない。欠測は散発ではなく SQ 周期に沿った連続した数日で、実取引日 2,093 日と実 SQ 暦 105 限月の照合では**最大 19 暦日**（2019-05、GW と重なった回）連続する。reading rules の staleness はこの構造に合わせて override してある。

**`term` は 517/524 日（98.7%）** で、限月が 2 つあれば出る。

**差を取る 2 つが揃って出ない日が 7 日ある**（2019-10-01 / 2019-12-06 / 2020-03-23 / 2020-04-08 / 2020-04-30 / 2021-02-26 / 2026-02-04）。いずれも ATM 前後 ±10% の同一行使価格でプットとコールの IV が中央値 12 ポイント超食い違った日である。プットコールパリティ上この 2 つは一致すべきなので、出所側が両側を揃った基準で出せていない。`iv30` はプットとコールの平均で、この食い違いは両側を反対向きに動かすので平均に残らず、これらの日も値を持つ（最大の食い違いだった 2020-04-08 は put 46.53 / call 28.01 に対し平均 37.27 で、前後の 36.72 / 36.30 の間に収まる）。

## 5. この結果が意味しないこと

- **買い時を告げるものではない。** #668 の計測で、下落局面でも通過候補数は広がらない（60d ≤ −5% で 396 対 +5% 超で 381）ことが確認されている。律速は候補でなく確信であり、IV はその確信を支える観測であって、建てる / 建てないを決める規則ではない。
- **分位は固定ではない。** 標本は 8.5 年で、この期間に含まれる大きな崩落は COVID 1 回だけである。より深い崩落が来れば上側の分位は動く。水準判断の正本を reading の `percentile` に置くのはこのためでもある。
- **4 営業日ごとの標本である。** 単日の突出は取りこぼしうるので、p99 と最大値は実際の極値より低い。また `iv30` / `skew` は曜日ごとの充足率が違う（水曜は月曜より 39% 多く残る。30 日を挟む条件が限月位置と連動するため）。曜日を等重みに直しても中央値は 0.14 ポイント以内しか動かないが、「曜日が均等」なのは行であって観測ではない。
- **`term` は 30 日満期化していない。** 2 限月の差そのものなので補間する第 3 の点がなく、手前限月がどこにあるかで意味が動く（`corr(手前限月日数, term) = +0.104`、満期帯別の中央値 −0.17〜+0.35）。`skew` は 30 日へ補間してあり、同じ相関は **−0.031**、満期帯別の中央値も 3.43 / 3.54 / 3.60 / 3.58 で単調でない。
- **`skew` / `term` を出さない基準は出所の食い違いの大きさで引いている。** その分布は標本の `near_gap` / `far_gap` 列にあり、p50 = 1.72 / p90 = 5.78 / p95 = 8.07 / p99 = 12.43 / 最大 20.35。境界の 12 はこの通常域の上端であると同時に、近傍日と比べた skew のずれが現れ始める点でもある（|gap| ≤ 12 で残差の中央値はほぼ 0、12 超で +0.67）。
