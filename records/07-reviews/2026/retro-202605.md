## 売買戦略の振り返り

### 適切だった点

- 全銘柄が小さめの現物 starter で、1 銘柄あたりの実資金 concentration は 2.55% から 4.06% に収まった。
- 5 銘柄合計でも entry notional は tactical budget 1,000,000 円に対して 92.42% で、stop 到達時の想定損失は -62,200 円に限定されている。
- 9692 と 8255 は絶対 return ではプラスで、個別 thesis が完全に外れたとはまだ言えない。closed position が 0 件のため、成功 / 失敗分類は未確定。

### 不適切だった点

- Nikkei が保有期間加重で +5.11% 上がった局面で、portfolio は +0.75% に留まった。絶対損失を避けても、benchmark relative では明確に負けている。
- 9682、9692、9470 の 3 銘柄は全て `sales-discount-growth` かつ情報・通信業で、deployed notional の 64.24% を占めた。validator warning の sector concentration を実運用の追加 entry 制約まで落とせていなかった。
- 3539 は `macro_context_fit.context_freshness: stale` を明示し starter に抑えたが、そもそも 2026-05-04 macro context の valid window を過ぎた後に新規買いを出している。caution と sizing だけでは、上昇相場への追随可否までは検査できていない。
- `price_missing_counts` が 19 / 19 のままで、標準の +15bd / +30bd tracking が機械的に埋まっていない。今回の振り返りも fallback source による手計算であり、feedback loop の再現性が弱い。

### 見落としたもの

- Entry 前に「候補銘柄の割安さ」だけでなく、「日経平均と sector に対して直近で勝っているか」を数値化していなかった。
- Screening 日から order / fill 日までの drift を十分に扱っていない。2026-05-01 / 2026-05-08 candidates を使い続けるなら、発注直前に candidate freshness と相対 momentum を更新する必要がある。
- Sector / playbook concentration を portfolio-level risk として扱う運用が弱かった。1 銘柄単位の sizing は抑えられていたが、同じ thesis の同時保有が benchmark 劣後を増幅した。
- Missed opportunity tracking が欠損したままなので、見送り銘柄 9 件が実は指数上昇を取り込めていたのか、それとも同じく弱かったのかを判断できない。

## 改善策

次回 cycle では playbook 自体の閾値を急に変えない。closed sample が 0 件で、playbook 別サンプルも 10 件未満のため、まず運用 checklist を変える。

1. Entry 前 packet に、候補銘柄の entry 直前終値、Nikkei return、sector / peer return、relative return を必須欄として追加する。Nikkei または sector に 3pt 以上劣後している候補は、thesis が event-driven でない限り starter size に限定する。
2. 同一 sector または同一 playbook の deployed notional が 50% を超える場合、追加 entry 前に exposure review を作る。超過を許す場合は、相関が低い理由を research / trade に明記する。
3. J-Quants の review price が取得できない場合の fallback を決める。最低限、みんかぶ daily_bar など同一 source で +15bd / +30bd と日経平均を同時に取り、retro で null のままにしない。
4. Macro context の `valid_until` を過ぎた後の新規 entry は、`context_freshness: stale` で starter にするだけでなく、macro context 更新 issue または明示的な exception を必要にする。
