# Watchlist

`records/_watchlist/` は、標準 screening universe や formal research の外にあるが、ユーザー判断で
継続確認したい銘柄を記録する support area です。

Watch-only は採用判断ではありません。`records/04-candidates/` の fact snapshot、
`records/05-research/` の investment memo、`records/_ledger/` の decision register とは
分けて扱います。

## 運用ルール

- 標準 universe に入らない銘柄は、watch-only に記録しても formal research へ昇格させない。
- Formal research へ進める場合は、標準 candidates に入った後、または明示的な例外承認を受けた後にする。
- Watch-only entry には、追加理由、標準 universe から外れた理由、次に見る trigger を残す。
- 株価や指標は記録時点の snapshot として扱い、最新値の正本にしない。
